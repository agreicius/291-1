    Section 0.1 Sets and tuples

    The two main players in the story of linear algebra are vector spaces and linear transformations. As we will see, a vector space is a certain kind of set, and a linear transformation is a special type of function. Moreover, many of the examples of vectors spaces we study will consist of tuples of real numbers. Accordingly, in the next two sections we will gather important notions and notations related to sets, tuples, and functions.
    🔗

    Subsection 0.1.1 Sets

    Definition 0.1.1. Sets.

    A set is a collection of objects. An object \(x\) is a member (or element) of a set \(A\) if \(A\) contains \(x\text{.}\) In this case, we write \(x \in A\text{.}\) If \(x\) is not a member of \(A\text{,}\) we write \(x \notin A\text{.}\)
    🔗
    🔗
    We use curly braces to describe the contents of a set. For example, \(A=\{1,2,3\}\) is the set containing the first three positive integers, and \(B=\{1,2,3,\dots\}\) is the set of all positive integers. The defining property of sets is that they are completely determined by their members, and nothing more. In particular, when describing sets as above, it does not matter in what order the elements are listed, nor if they are repeated: e.g., \(\{1,2,3\}\text{,}\) \(\{2,1,3\}\text{,}\) and \(\{2,1,1,3,2\}\) are three descriptions of the same set. This somewhat slippery notion is made perfectly clear by specifying exactly what it means for two sets to be equal, as we do below.
    🔗

    Definition 0.1.2. Set equality.

    Sets \(A\) and \(B\) are equal, denoted \(A=B\text{,}\) if they have precisely the same elements: i.e., if for any object \(x\text{,}\) we have \(x\in A\) if and only if \(x\in B\text{.}\)
    🔗
    🔗
    Set membership naturally extends to a notion of one set being within another. Formally, this is captured by the relation of set inclusion.
    🔗

    Definition 0.1.3. Set inclusion.

    A set \(A\) is a subset of a set \(B\text{,}\) denoted \(A \subseteq B\text{,}\) if every member of \(A\) is a member of \(B\text{:}\) i.e., \(x\in A\) implies \(x\in B\) for any object \(x\text{.}\) The relation \(A\subseteq B\) is called set inclusion.
    🔗
    🔗

    Remark 0.1.4.

    The definitions of set equality and the subset relation make use of two important logical operations: namely, the “if and only if” (or “iff” for short) and “if-then” operations. We describe these notions in more detail in Logic, and we outline techniques for proving “if and only if” and “if-then” statements, including statements about set equality and the subset relation, in Proof techniques.
    🔗
    🔗
    With the fundamental notions of membership, equality, and subset in place, we now introduce means of building new sets from existing ones. The first is a manner of carving out a subset of a given set using a specified property.
    🔗

    Definition 0.1.5. Set-builder notation.

    Let \(A\) be a set, and let \(P\) be a property that elements of \(A\) either satisfy or do not satisfy. For an element \(x\in A\text{,}\) let \(P(x)\) denote the statement that \(x\) satisfies \(P\text{.}\) The set of all elements of \(A\) satisfying \(P\) is denoted
    \begin{equation*} \{x \in A \colon P(x) \}\text{.} \end{equation*}
    🔗
    🔗

    Remark 0.1.6. Parsing set builder notation.

    Set builder notation ‘\(\{x \in A\colon P(x)\}\)’ is parsed from left to right as follows:
    • ‘\(\{\)’ is read as “the set of”
      🔗
      🔗
    • ‘\(x\in A\)’ is read as “elements of \(A\)”
      🔗
      🔗
    • ‘\(\colon\)’ is read as “such that”
      🔗
      🔗
    • ‘\(P(x)\)’ is read as “\(P(x)\) is true”.
      🔗
      🔗
    Taken altogether we get: “The set of elements of \(A\) such that \(P(x)\) is true”.
    🔗
    🔗

    Example 0.1.7.

    Let \(A=\{0,1,2,\dots \}\) be the set of nonnegative integers. The subset \(B=\{0,2,4,\dots\}\) of even positive integers can be described using set-builder notation as
    \begin{equation*} B=\{x\in A\colon x \text{ is even}\}\text{,} \end{equation*}
    or alternatively,
    \begin{equation*} B=\{x\in A\colon x=2k \text{ for some integer } k\}\text{.} \end{equation*}
    🔗
    🔗
    Next we use set builder notation, the set membership relation, and some basic logic to define the union, intersection, and difference of sets.
    🔗

    Definition 0.1.8. Union, intersection, difference, and complement.

    Let \(A\) and \(B\) be subsets of a common set \(X\text{.}\)
    • Set union.
      The union \(A \cup B\) of \(A\) and \(B\) is defined as
      \begin{equation*} A\cup B=\{x\in X\colon x\in A\text{ or } x\in B\}\text{.} \end{equation*}
      More generally, the union \(A_1\cup A_2\dots \cup A_n\) of a collection of subsets of \(A_i\subseteq X\) is defined as
      \begin{equation*} A_1\cup A_2\dots \cup A_n=\{x\in X\colon x\in A_i \text{ for some } 1\leq i\leq n\}\text{.} \end{equation*}
      🔗
      🔗
    • Set intersection.
      The intersection \(A \cap B\) of \(A\) and \(B\) is defined as
      \begin{equation*} A\cap B=\{x\in X\colon x\in A\text{ and } x\in B\}\text{.} \end{equation*}
      More generally, the intersection \(A_1\cap A_2\dots \cap A_n\) of a collection of subsets of \(A_i\subseteq X\) is defined as
      \begin{equation*} A_1\cap A_2\dots \cap A_n=\{x\in X\colon x\in A_i \text{ for all } 1\leq i\leq n\}. \end{equation*}
      🔗
      🔗
    • Set difference.
      The difference \(A-B\) is defined as
      \begin{equation*} A-B=\{x\in X\colon x\in A\text{ and } x\notin B\}\text{.} \end{equation*}
      🔗
      🔗
    • Set complement.
      The complement of \(A\) in \(X\) is defined as \(X-A\text{.}\) In contexts where there is clear what the larger set \(X\) is, we denote the complement of \(A\) in \(X\) as \(A^c\text{.}\)
      🔗
      🔗
    🔗
    🔗
    With the help of these set operations, we can now describe some common sets used in mathematics.
    🔗

    Definition 0.1.9. Common mathematical sets.

    The empty set is the set containing no objects, denoted \(\{\ \}\) or \(\emptyset\text{.}\)
    🔗
    We denote by \(\mathbb{R}\) the set of all real numbers. The integers \(\Z\) and rational numbers \(\mathbb{Q}\) are the subsets of \(\R\) defined as
    \begin{align*} \mathbb{Z} \amp =\{0,1,2,3,\dots\}\cup \{-1,-2,-3,\dots\} \\ \mathbb{Q} \amp = \{x\in\mathbb{R}\colon x=\tfrac{m}{n} \text{ for some } m,n\in\Z\} \text{.} \end{align*}
    This yields the following chain of subsets:
    \begin{equation} \mathbb{Z}\subseteq\mathbb{Q}\subseteq\mathbb{R}\text{.}\tag{0.1.1} \end{equation}
    Additionally, for any integer \(a\in \Z\) we denote by \(\Z_{\geq a}\) the set of all integers \(n\geq a\text{:}\) i.e.,
    \begin{equation*} \Z_{\geq a}=\{n\in \Z\colon n\geq a\}=\{a,a+1,a+2,\dots, \}\text{.} \end{equation*}
    Lastly, we denote by \(\Z_+\) the set of all positive integers: i.e.,
    \begin{equation*} \Z_+=\{n\in \Z\colon n\geq 0\}=\{1,2,\dots, \}\text{.} \end{equation*}
    🔗
    🔗
    Lastly, we define the cardinality of a set \(A\text{,}\) which is a measure of its size. Essentially this is just the number of distinct elements of the set \(A\text{.}\) However, we take care that our definition encompasses both finite and infinite sets.
    🔗

    Definition 0.1.10. Cardinality of a set.

    Let \(A\) be a set. The cardinality of \(A\), denoted \(\val{A}\) is defined as follows.
    • If \(A\) is finite, then its cardinality is the number \(n\) of distinct elements it contains, written \(\val{A}=n\text{.}\)
      🔗
      🔗
    • If \(A\) is infinite, then we say it has infinite cardinality, and write \(\val{A}=\infty\text{.}\)
      🔗
      🔗
    🔗
    🔗
    🔗

    Subsection 0.1.2 Tuples

    A set is a somewhat paltry thing, structurally speaking. You can think of it as an arbitrary collection of objects thrown into a bag with no real rhyme or reason. In particular, as is commonly said, there is no order to the elements of a set. That is, when we write \(A=\{1,2,3\}\text{,}\) there is no sense in which \(1\) is the first element of \(A\text{,}\) \(2\) is the second element, and \(3\) is the third. That particular ordering is simply suggested by the way we have chosen to describe \(A\text{,}\) but recall that we could just have well described \(A\) as \(\{2,1,3\}\) or even \(\{2,1,1,3, 3, 2\}\text{.}\) To give an ordering to \(A\) we need to explicitly state which element is the the first, which the second, and which the third. Clearly, this is an additional layer of structure given to the underlying set \(A\text{,}\) and the typical way to indicate this structure is to use what is often called ordered list, or sequence notation. For example, we write \(A=(1,2,3)\) to denote the set \(A\) along with the choice of ordering that designates \(1\) as the first element, \(2\) as the second, and \(3\) as the third; and we write \(A=(2,3,1)\) to denote the same set along with the ordering that designates \(2\) as the first element, \(3\) as the second, and \(1\) as the third. Our definition of a tuple both makes this notion of an ordered set precise and greatly generalizes it.
    🔗

    Definition 0.1.11. Tuples.

    Let \(I\) and \(A\) be sets. An \(A\)-valued tuple indexed by \(I\) is a rule that assigns to each index \(i\in I\) an element \(a_i\in A\text{,}\) denoted \((a_i)_{i\in I}\text{.}\)
    🔗
    Given an \(A\)-valued tuple \((a_i)_{i\in I}\text{,}\) we call \(I\) the index set, and for each index \(i\in I\text{,}\) we call \(a_i\) the \(i\)-th component (or coordinate, or entry, or term) of \((a_i)_{i\in I}\text{.}\) We call \(\{a_i\mid i\in I\}\) the set of values of the tuple \((a_i)_{i\in I}\text{.}\)
    🔗
    The set of all \(A\)-valued tuples indexed by \(I\) is denoted \(A^I\text{:}\)i.e.,
    \begin{equation*} A^I=\{(a_i)_{i\in I}\mid a_i\in A \text{ for all } i\in I\}\text{.} \end{equation*}
    🔗
    🔗

    Notation 0.1.12. Tuple notation.

    Different index sets give rise to different notational conventions for denoting tuples \((a_i)_{i\in I}\) and sets of tuples \(A^I\text{.}\)
    • When \(I=\{1,2,\dots, n\}\) for some positive integer \(n\text{,}\) we will write \(A^n\) for \(A^I\text{,}\) and will use any of the following notations for a tuple of \(A^n\text{:}\)
      \begin{align*} (a_i)_{i\in I}\amp\amp (a_i)_{i=1}^n \amp\amp (a_1,a_2,\dots,a_n) \text{.} \end{align*}
      In this case we call \((a_i)_{i=1}^n\) an \(n\)-tuple with values in \(A\text{,}\) and we call \(n\) the length of the \(n\)-tuple. Moreover, we use the following terminology for \(n=2,3\text{:}\) a \(2\)-tuple \((a_1,a_2)\) is a called a pair of elements of \(A\text{,}\) a \(3\)-tuple \((a_1,a_2,a_3)\) is called a triple of elements of \(A\text{.}\)
      🔗
      🔗
    • When \(I=\Z_{\geq 1}=\{1,2,\dots\}\text{,}\) we will write \(A^\infty\) for \(A^I\text{,}\) and will use any of the following notations for a tuple of \(A^\infty\text{:}\)
      \begin{align*} (a_i)_{i\in I}\amp\amp (a_i)_{i=1}^\infty \amp\amp (a_1,a_2,\dots) \text{.} \end{align*}
      In this context a tuple of \(A^\infty\) is often called an infinite sequence of elements of \(A\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Given a tuple \((a_i)_{i\in I}\text{,}\) the indexing by the set \(I\) plays the role of a filing system: given an index \(i\in I\text{,}\) our filing system returns to us a certain element \(a_i\) of \(A\) and labels it the \(i\)-th element in our system. Different index sets, and different choices of index assignments, give rise to different ways of organizing the elements of the underlying set \(A\text{.}\) This is the motivation for the following definition of what it means for two \(A\)-valued tuples to be equal.
    🔗

    Definition 0.1.13. Tuple equality.

    Given a set \(A\text{,}\) two \(A\)-valued tuples \((a_i)_{i\in I}\) and \((b_j)_{j\in J}\) are equal, denoted \((a_i)_{i\in I}=(b_j)_{j\in J}\) if the following two conditions hold.
    1. \(I=J\text{.}\)
      🔗
      🔗
    2. \(a_i=b_i\) for all \(i\in I\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Remark 0.1.14. Tuple equality.

    The filing system analogy for tuples might help you make sense of Definition 0.1.13. For two filing systems of a certain collection to be equal, they should firstly have the same indexing set (this is the condition \(I=J\)); and secondly, to each index in our indexing set, they should assign the same object from our collection.
    🔗
    🔗

    Example 0.1.15. Tuple equality.

    Decide whether the given \(\R\)-valued tuples are equal.
    1. \(\bolda=(1,2,3)\text{,}\) \(\boldb=(1,2,4)\)
      🔗
      🔗
    2. \(\bolda=(1,2,3)\text{,}\) \(\boldb=(3,2,1)\)
      🔗
      🔗
    3. \(\bolda=(1,1,1)\text{,}\) \(\boldb=(1,1,1,1)\)
      🔗
      🔗
    🔗
    Solution.
    In all cases we have \(\bolda\ne \boldb\text{,}\) but for different reasons that illuminate the different nuances of Definition 0.1.13.
    1. Both tuples have the same index set \(I=\{1,2,3\}\) in this case. Write \(\bolda=(1,2,3)=(a_1,a_2,a_3)\) and \(\boldb=(1,2,4)=(b_1,b_2,b_3)\text{.}\) Although we have \(a_1=b_1\) and \(a_2=b_2\text{,}\) since \(a_3\ne b_3\text{,}\) we see that \(\bolda\ne\boldb\text{.}\) Note that in this case we do not even have equality between the set of values of the two tuples. That is, \(\{a_1,a_2,a_3\}=\{1,2,3\}\ne \{1,2,4\}=\{b_1,b_2,b_3\}\text{.}\)
      🔗
      🔗
    2. Again, both tuples are indexed by \(I=\{1,2,3\}\text{.}\) Furthermore, in this case the sets of values of the two tuples are equal. However, since the third coordinate of \(\bolda\) is not equal to the third coordinate of \(\boldb\text{,}\) we have \(\bolda\ne \boldb\text{.}\)
      🔗
      🔗
    3. In this case the two tuples fail to be equal due to their having different index sets. The index set of \(\bolda\) is \(I=\{1,2,3\}\text{,}\) and the index set of \(\boldb\) is \(J=\{1,2,3,4\}\text{.}\)
      🔗
      🔗

    Remark 0.1.16. Ordered list.

    Index sets of the form \(I=\{1,2,\dots, n\}\) and \(I=\{1,2,\dots \}\) are equipped with a natural choice of ordering inherited from the \(<\) relation on \(\Z\text{.}\) That is, we have
    \begin{equation*} 1< 2< 3<\dots \text{.} \end{equation*}
    As a result, a tuple \((a_1,a_2,\dots, a_n)\) (or \((a_1,a_2,\dots)\)) indexed by \(I\) for one of these types of index sets can be thought of as an ordering of the underlying set. Indeed, in this setting we do not just speak of the \(i\)-th element of the tuple \((a_i)_{i\in I}\text{,}\) we further call \(a_1\) the first element, \(a_2\) the second element, etc.. This is why tuples of the form \((a_i)_{i=1}^n\) or \((a_i)_{i=1}^\infty\) are often called ordered lists or ordered sequences.
    🔗
    We take care to add however, that since our general definition of tuples allows for arbitrary index sets \(I\text{,}\) and since not every set \(I\) has a natural choice of ordering, we should not in general think of tuples as ordered lists in this precise sense. Indeed, consider the somewhat peculiar index set \(I=\{\dagger,*, !\}\text{.}\) There is no natural ordering of the set \(I\text{,}\) and so a tuple \((a_i)_{i\in I}\) indexed by \(I\) also should not be thought of as an ordered list. Indeed, instead of speaking of a first, second, or third element of the tuple \((a_i)_{i\in I}\text{,}\) it really only makes sense to speak of the \(\dagger\)-th, \(*\)-th, and \(!\)-th element of the tuple!
    🔗
    🔗
    There is no restriction to what the elements of a set \(A\) are. In particular, these elements could be sets themselves! For example, the set
    \begin{equation*} A=\{\{\},\{1\},\{1,2\}\} \end{equation*}
    contains three elements, all of which are themselves sets: namely, the empty set, the set \(\{1\}\text{,}\) and the set \(\{1,2\}\text{.}\) Similarly, our definition of tuples gives no restrictions on what type of objects the coordinates \(a_i\) are allowed to be. When we let those coordinates be sets themselves, we arrive at the mathematical notion of a indexed family of sets.
    🔗

    Definition 0.1.17. Indexed family of sets.

    An indexed family of sets is a tuple \(\mathcal{F}=(A_i)_{i\in I}\text{,}\) where \(A_i\) is a set for all indices \(i\in I\text{.}\)
    🔗
    🔗
    The notion of a family of sets allows us in turn to generalize our definitions of finite unions and intersections to arbitrary unions and intersections.
    🔗

    Definition 0.1.18. Arbitrary unions and intersections.

    Let \(A\) be a set, and let \((A_i)_{i\in I}\) be a family of sets with \(A_i\subseteq A\) for all \(i\in I\text{.}\)
    • The union of the \(A_i\text{,}\) denoted \(\bigcup_{i\in I}A_i\text{,}\) is defined as
      \begin{align} \bigcup_{i\in I}A_i \amp =\{a\in A\mid a\in A_i\text{ for some } i\in I\}\text{.}\tag{0.1.2} \end{align}
      🔗
      🔗
    • The intersection of the \(A_i\text{,}\) denoted \(\bigcap_{i\in I}A_i\text{,}\) is defined as
      \begin{align} \bigcap_{i\in I}A_i \amp =\{a\in A\mid a\in A_i\text{ for all } i\in I\}\text{.}\tag{0.1.3} \end{align}
      🔗
      🔗
    🔗
    🔗
    Lastly, combining the notions of families of sets and tuples, we arrive at the notion of a Cartesian product, which can be thought of as the set of tuples whose coordinates are restricted to a specified subset \(A_i\) for all \(i\text{.}\)
    🔗

    Definition 0.1.19. Cartesian product.

    Let \(A\) be a set, and let \((A_i)_{i\in I}\) be a family of subsets with \(A_i\subseteq A\) for all \(i\in I\text{.}\) The Cartesian product \(\prod_{i\in I}A_i\) of the \(A_i\) is defined as
    \begin{align*} \prod_{i\in I}A_i\amp =\{(a_i)_{i\in I}\in A^I\mid a_i\in A_i \text{ for all } i\in I\} \text{.} \end{align*}
    In other words, the Cartesian product is the set of all \(A\)-valued tuples whose \(i\)-th coordinate is an element of \(A_i\) for all \(i\in I\text{.}\)
    🔗
    In the special case where \(I=\{1,2,\dots, n\}\) we write
    \begin{align*} \prod_{i\in \{1,2,\dots, n\}}A_i \amp =A_1\times A_2\times \cdots A_n \amp \\ \amp = \{(a_1,a_2,\dots, a_n)\colon a_i\in A_i \text{ for all } 1\leq i\leq n\} \end{align*}
    and
    \begin{equation*} A^{\{1,2,\dots, n\}}=A^n\text{,} \end{equation*}
    and we call \(A^n\) the \(n\)-fold Cartesian product of \(A\).

    Section 1.4 Vector spaces

    In the last sections we’ve been busy with isolating familiar arithmetic properties of \(\R\) and generalizing them in the form of our axiomatic definition of a field (Definition 1.2.5). In introducing vector spaces in this section, we will go at things the other way around: we will axiomatically define a mathematical object called a vector space without having an original inspirational model, and then start building up a collection examples that you may not have been exposed to before.
    🔗

    Subsection 1.4.1 Definition and first examples

    Fiat 1.4.1. \(F\) stands for field.

    Henceforth, unless stated otherwise, \(F\) will always denote a field and all statements of theory formulated in terms of \(F\) are understood to be valid for any field.
    🔗
    🔗

    Definition 1.4.2. Vector space.

    Let \(F\) be a field. A vector space over \(F\) (or \(F\)-vector space) is a set \(V\) together with two operations
    \begin{align*} V\times V \amp \rightarrow V \amp F\times V\amp \rightarrow V\\ (v,w) \amp\mapsto v+w \amp (c,v)\amp \mapsto cv \text{,} \end{align*}
    called respectively vector addition and scalar multiplication, that satisfy the following vector space axioms.
    1. Vector addition is commutative.
      \(v+w=w+v\) for all \(v,w\in V\text{.}\)
      🔗
      🔗
    2. Vector addition is associative.
      \((u+v)+w=u+(v+w)\) for all \(u, v, w\in V\text{.}\)
      🔗
      🔗
    3. Zero vector.
      There is an element \(\boldzero\in V\) such that for all \(v\in V\text{,}\) we have
      \begin{equation} \boldzero+v=v\text{.}\tag{1.4.1} \end{equation}
      We call \(\boldzero\) the zero vector of \(V\text{.}\)
      🔗
      🔗
    4. Vector inverses.
      For all \(v\in V\text{,}\) there is another element \(-v\) satisfying
      \begin{equation} -v+v=\boldzero\text{.}\tag{1.4.2} \end{equation}
      We call \(-v\) the vector inverse of \(v\text{.}\)
      🔗
      🔗
    5. Distribution over vector addition.
      \(c(v+w)=cv+cw\) for all \(c\in F\) and \(v, w\in V\text{.}\)
      🔗
      🔗
    6. Distribution over scalar addition.
      \((c+d)v=cv+dv\) for all \(c,d\in F\) and \(v\in V\text{.}\)
      🔗
      🔗
    7. Scalar multiplication is associative.
      \(c(dv)=(cd)v\) for all \(c,d\in F\) and all \(v\in V\text{.}\)
      🔗
      🔗
    8. Scalar multiplication identity.
      \(1\,v=v\) for all \(v\in V\text{.}\)
      🔗
      🔗
    We call elements of the vector space \(V\) vectors and the elements of \(F\) scalars.
    🔗
    🔗

    Remark 1.4.3. Arithmetic and existential axioms.

    As with the axioms in Definition 1.2.5 we divide the vector space axioms into the arithmetic axioms (Axioms (i)-(ii),(v)-(vi),(vii)) and the existential axioms (Axioms (iii)-(iv)).
    🔗
    🔗

    Remark 1.4.4. Scalar multiplication: a hybrid operation.

    There are certainly some similarities between Definition 1.4.2 and Definition 1.2.5, but we should point out one very important qualitative difference between the structural operations that define these two mathematical objects. Namely, note that the scalar multiplication operation that forms part of the definition of a vector space is a hybrid operation in the sense that it takes as input a pair \((c,v)\text{,}\) where \(c\in F\) is an element of the field (or scalar as we now call it), and \(v\in V\) is an element of the vector space, and outputs a new element \(cv\) of the vector space.
    🔗
    🔗
    We now proceed to a litany of examples. Each one will be stated as a definition (for reference purposes), but nonetheless requires a proof that the given structure does indeed constitute a vector space. In a classic mathematical move, we begin with the simplest of all vector spaces, the zero space. Elementary as this example is, it serves well to illustrate the axiomatic nature of Definition 1.4.2.
    🔗

    Definition 1.4.5. Zero space.

    Let \(F\) be a field, and let \(V=\{\bot\}\text{,}\) a set containing exactly one element. There is a unique \(F\)-vector space structure that can be given to \(V\text{,}\) defined as follows.
    • Vector operations.
      Vector addition on \(V\) is defined as \(\bot+\bot=\bot\text{;}\) scalar multiplication on \(V\) is defined as \(c\cdot \bot=\bot\) for all \(c\in F\text{.}\)
      🔗
      🔗
    • Zero vector.
      The zero vector of \(V\) is \(\bot\text{:}\) i.e., \(\boldzero=\bot\text{.}\)
      🔗
      🔗
    • Vector inverses.
      The vector inverse of \(\bot\) is \(\bot\text{:}\) i.e., \(-\bot=\bot\text{.}\)
      🔗
      🔗
    Since the unique element \(\bot\in V\) ends up serving as the zero vector, we have \(V=\{\boldzero\}\)and call \(V\) a zero space.
    🔗
    🔗
    Definition 1.4.5 makes two claims: that the given operations make \(V=\{\bot\}\) into a vector space, and that this is the only way to make \(V=\{\bot\}\) into a vector space. As with all claims in mathematics, these need to be proved, but as you will see, the proof is a very light affair.
    🔗

    Proof for Definition 1.4.5.

    Since \(V=\{\bot\}\) only has one item, there is no choice for what vector addition \(V\times V\rightarrow V\) and scalar multiplication \(F\times V\rightarrow V\) can be. They must be defined in the manner given in Definition 1.4.5. Similarly, we must have \(\boldzero=\bot\) and \(-\bot=\bot\text{,}\) as once again, \(\bot\) is the only element of \(V\text{!}\) This shows that there can be at most one way of giving \(V\) a vector space structure.
    🔗
    It is now easy to see that these choices do indeed satisfy the vector space axioms. That \(\bot\) satisfies the identity of Axiom iii defining the zero vector \(\boldzero\) follows from the fact that for all \(v\in V\) we have \(v=\bot\) (since \(V=\{\bot\}\)), and thus
    \begin{align*} \bot+v \amp =\bot+\bot\\ \amp = \bot\\ \amp =v\text{.} \end{align*}
    Thus \(\bot=\boldzero\) is the zero vector of the space.
    🔗
    Similarly, to show all elements of \(V\) have vector inverses amounts to showing that \(\bot\) has a vector inverse, since this is the only element of \(V\text{.}\) It is claimed that \(-\bot=\bot\) (i.e., \(\bot\) is its own vector inverse), which follows from the fact that
    \begin{align*} -\bot+\bot \amp = \bot+\bot\\ \amp = \bot\\ \amp = \boldzero\text{.} \end{align*}
    Lastly, the identities of Axioms (i)-(ii) and (v)-(viii) in this setting all reduce to trivial statements of the form \(\bot+\bot=\bot+\bot\text{.}\) Consider Axiom (vii), for example. For all \(v,w\in V\text{,}\) we have \(v=w=\bot\text{,}\) in which case
    \begin{align*} c(v+w) \amp =c(\bot+\bot) \\ \amp =c\cdot \bot\\ \amp = \bot \amp \text{(def. of sc. mult.)} \end{align*}
    and
    \begin{align*} cv+dw \amp =c\cdot \bot+d\cdot \bot\\ \amp = \bot+\bot\\ \amp =\bot\text{.} \end{align*}
    Thus
    \begin{equation*} c(v+w)=\bot=cv+dw \end{equation*}
    for all \(v, w\in V\) and \(c\in F\text{.}\)
    🔗
    We leave verification of the rest of the axioms to the reader.
    🔗
    🔗
    It is worth formalizing the proof technique used above into an official procedure for showing whether something is a vector space.
    🔗

    Procedure 1.4.6. Vector space verification.

    To decide whether a given set and operations is a vector space, proceed as follows.
    1. Make explicit the underlying set \(V\) of the proposed vector space.
      🔗
      🔗
    2. Make explicit what the scalar multiplication and vector addition operations are.
      🔗
      🔗
    3. Identify an element of \(V\) that serves as the zero vector (i.e., satisfies (1.4.1)) and for each \(\boldv\in V\) show that there is a vector \(-\boldv\) satisfying (1.4.2).
      🔗
      🔗
    4. Show that the two vector operations and our choice of zero vector and vector inverses satisfy the axioms of Definition 1.4.2.
      🔗
      🔗
    🔗
    🔗

    Remark 1.4.7. Vector space verification.

    Think of steps (1)-(3) of Procedure 1.4.6 as the issuing of official declarations about the makeup of our proposed vector space: “The underlying set shall be as stated”; “We declare the vector operations thusly”; “The zero vector shall be this element here, and vector inverses shall be assigned in this manner”. Step (4) is where we get down to the nitty gritty of showing that the proposed vector space structure articulated in (1)-(3) does indeed satisfy all the necessary properties.
    🔗
    In each of the remaining examples below we carefully lay out the details of items (1)-(3) while often leaving much of the work of item (4) to you. You will meet these vector spaces frequently throughout the rest of your life. Each time you do, it will be helpful for orientation purposes to mentally run through items (1)-(3). Ask yourself: What is the underlying set? What are vector operations? What acts as the zero vector, and how do I assign vector inverses?
    🔗
    🔗

    Example 1.4.8. Fields are vector spaces.

    Show that a field \(F\) is a vector space, where vector addition is field addition, and scalar multiplication is field multiplication.
    🔗
    Solution.
    The underlying set and operations have already been specified. We add that the field element \(0\in F\) will serve as the zero vector (i.e., we have \(\boldzero=0\)), and for each \(a\in F\text{,}\) its vector inverse will be the field additive inverse \(-a\text{.}\)
    🔗
    That our proposed vector space operations, zero vector, and vector inverses satisfy the axioms of Definition 1.4.2 now follows essentially immediately from the field axioms satisfied by \(F\text{!}\) For example, the vector space arithmetic axioms (i)-(ii), (v)-(viii) in this context are simply restatements that field addition is commutative and associative, that field multiplication distributes over field addition, that field multiplication is associative, and that \(1\in F\) satisfies the multiplicative identity property. Similarly, the zero vector identity is identical to the additive identity property of fields, giving us axiom (iii), and the vector inverse identity is identical to the additive inverse property of fields, giving us axiom (iv).
    🔗
    🔗
    🔗

    Example 1.4.9. \(F^2\) is a vector space.

    Let \(F\) be a field, and let \(F^2=F\times F\) be the set of all pairs of elements of \(F\text{:}\) i.e., \(F^2=\{(a,b)\mid a,b\in F\}\text{.}\)
    🔗
    Define vector addition and scalar multiplication on \(F^2\) as follows:
    • given \(v=(a,b), w=(c,d)\in F^2\text{,}\) define \(v+w=(a+c,b+d)\text{;}\)
      🔗
      🔗
    • given \(c\in F\) and \(v=(a,b)\in F^2\text{,}\) define \(cv=(ca,cb)\text{.}\)
      🔗
      🔗
    Show that \(F^2\) is a vector space with respect to these two operations.
    🔗
    Solution.
    Let’s follow the steps of Procedure 1.4.6. Once again, the underlying set and vector operations have been specified. We further declare that the zero vector of \(F^2\) will be \(\boldzero=(0,0)\text{,}\) and that given any \(v=(a,b)\in F^2\text{,}\) its vector inverse shall be \(-v=(-a,-b)\text{.}\) Let’s verify some of the axioms. Let \(v=(a,b), w=(c,d), u=(e,f)\in F^2\text{.}\) We have
    \begin{align*} v+w \amp =(a+c,b+d)\\ \amp =(c+a,d+b) \amp \text{(field add. comm.)}\\ \amp =w+v\\ v+(w+u) \amp = (a,b)+(c+e,d+f)\\ \amp = (a+(c+e), b+(d+f))\\ \amp = ((a+c)+e, (b+d)+f) \amp \text{(field add. assoc.)}\\ \amp = (a+c,b+d)+(e,f)\\ \amp = (v+w)+u\text{,} \end{align*}
    showing that axioms (i)-(ii) hold. Axioms (v)-(viii) follow in a similar manner, ultimately citing some arithmetic properties of \(F\) itself. We leave those to the reader, and instead verify axioms (iii)-(iv). For all \(v=(a,b)\in F^2\text{,}\) we have
    \begin{align*} (0,0)+v \amp =(0+a, 0+b)\\ \amp = (a,b) \amp (\text{field add. ident.}) \\ (-a,-b)+(a,b) \amp =(-a+a, -b+b)\\ \amp =(0,0) \amp (\text{field add. inv.})\text{,} \end{align*}
    showing that \(\boldzero=(0,0)\) satisfies the zero vector identity, and \(-v=(-a,-b)\) satifies the vector inverse identity for \(v=(a,b)\text{.}\)
    🔗
    🔗
    🔗

    Definition 1.4.10. Vector space of \(F\)-valued functions.

    Let \(F\) be a field, and let \(X\) be a set. We denote by \(\mathcal{F}(X, F)\) or \(F^X\) the set of all functions \(f\colon X\rightarrow F\) with domain \(X\) and codomain \(F\text{.}\)
    🔗
    • Vector operations.
      Given functions \(f,g\in \mathcal{F}(X,F)\) and scalar \(c\in F\text{,}\) we let \(f+g\) be the function in \(\mathcal{F}(X,F)\) defined as
      \begin{equation*} (f+g)(x) =f(x)+g(x) \end{equation*}
      for all \(x\in X\text{,}\) and we let \(cf\) be the function in \(\mathcal{F}(X,F)\) defined as
      \begin{align*} (cf)(x)\amp =c f(x)\text{.} \end{align*}
      The operations
      \begin{align*} \mathcal{F}(X,F)\times \mathcal{F}(X,F) \amp \rightarrow \mathcal{F}(X,F) \amp F\times \mathcal{F}(X,F)\amp \rightarrow \mathcal{F}(X,F) \\ (f,g) \amp \mapsto f+g \amp (c,f)\amp \mapsto cf \end{align*}
      are called function addition and function scalar multiplication, respectively.
      🔗
      🔗
    • Zero vector.
      The zero vector of \(\mathcal{F}(X,F)\) is the zero function \(0_X\colon X\rightarrow F\) defined as \(0_X(x)=0\) for all \(x\in X\text{.}\)
      🔗
      🔗
    • Vector inverses.
      Given a function \(f\in \mathcal{F}(X,F)\text{,}\) its vector inverse is the function \(-f\in \mathcal{F}(X,F)\) defined as
      \begin{equation*} (-f)(x)=-f(x) \end{equation*}
      for all \(x\in X\text{.}\)
      🔗
      🔗
    We call \(\mathcal{X,F}\text{,}\) together with these vector operations, the space of functions from \(X\) to \(F\).
    🔗
    🔗

    Let \(F\) be a field, and let \(X\) be a set. The set \(\mathcal{F}(X,F)\) is a vector space with respect to function addition and function scalar multiplication.

    Example 1.4.12. Real-valued functions.

    Let \(I=[a,b]\subseteq \R \) be an interval in the real line. The vector operations on \(\mathcal{F}(I,\R)\) correspond to the function-arithmetic operations you met in precalculus and calculus: i.e., given functions \(f,g\in\mathcal{F}(I,\R)\text{,}\) their vector sum \(f+g\) is the function defined as \((f+g)(x)=f(x)+g(x)\) for all \(x\in [a,b]\text{.}\) Similarly, given a scalar \(c\in \R\) and function \(f\in \mathcal{F}(I,\R)\text{,}\) the vector scalar multiple \(cf\) is the function defined as \((cf)(x)=cf(x)\) for all \(x\in \R\text{.}\)
    🔗

    Subsection 1.4.2 Vector space properties

    We end this section with a few elementary vector space properties. Since these statements involve a general vector space (as opposed to a specific type of vector space), we will make no assumptions about \(V\) and the base field \(F\text{,}\) other than that \(V\) satisfies the vector space axioms and \(F\) satisfies the field axioms.
    🔗

    Proposition 1.4.14. Uniqueness of zero vector and inverses.

    Let \(V\) be an \(F\)-vector space.
    1. The zero vector in \(V\) is unique: i.e., there is one and only one element of \(V\) that satisfies (1.4.1).
      🔗
      🔗
    2. Inverse vectors are unique: i.e., for all \(v\in V\) there is one and only one vector \(-v\) satisfying (1.4.2).
      🔗
      🔗
    🔗
    🔗

    Proof.

    1. If \(w\in V\) satisfies \(w+v=v\) for all \(v\in V\text{,}\) then in particular, taking \(v=\boldzero\text{,}\) we see that \(w+\boldzero=\boldzero\text{.}\) But since \(w+\boldzero=w\) (using the defining property of \(\boldzero)\text{,}\) we see that
      \begin{align*} w+\boldzero=\boldzero \amp \implies w=\boldzero\text{.} \end{align*}
      We conclude that \(w=\boldzero\text{,}\) as desired.
      🔗
      🔗
    2. Let \(v\in V\text{.}\) Given \(w\in V\) we have
      \begin{align*} w+v =\boldzero \amp \implies w+v=-v+v \amp (-v+v=\boldzero) \\ \amp \implies w+v+(-v)=-v+v+(-v)\\ \amp \implies w+\boldzero=-v+\boldzero \amp (v+(-v)=\boldzero)\\ \amp \implies w=-v \amp (\text{prop. of } \boldzero)\text{.} \end{align*}
      🔗
      🔗
    🔗
    🔗

    Proposition 1.4.15. Vector space properties.

    Let \(V\) be an \(F\)-vector space.
    1. For all \(v\in V\text{,}\) we have \(0\boldv=\boldzero\text{.}\)
      🔗
      🔗
    2. For all \(c\in F\text{,}\) we have \(c\boldzero=\boldzero\text{.}\)
      🔗
      🔗
    3. For all \(v\in V\text{,}\) we have \((-1)\boldv=-\boldv\text{.}\)
      🔗
      🔗
    4. For all \(v\in V\) and \(c\in F\text{,}\) if \(cv=\boldzero\text{,}\) then \(c=0\) or \(v=\boldzero\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.

    We provide proofs of (1) and (3), leaving (2) and (4) to the reader.
    🔗
    Our proof of (1) is almost identical to a similar statement in Proposition 1.2.17. For any \(v\in V\text{,}\) we have
    \begin{align*} 0v \amp = (0+0)v \amp (\text{field prop. of } F)\\ \amp 0v+0v \amp (\text{dist. prop. of } V)\text{.} \end{align*}
    But then we have
    \begin{align*} 0v\amp = 0v+0v \\ -(0v)+0v\amp=-(0v)+0v+0v \amp (\text{add } -(0v)\text{ to both sides}) \\ \boldzero\amp=\boldzero+0v \amp (\text{vec. inv. prop.})\\ \boldzero\amp=0v \amp (\text{prop. of } \boldzero)\text{,} \end{align*}
    as desired.
    🔗
    Let \(v\in V\text{.}\) To prove (2), we will show that \((-1)v\) satisfies the defining property (1.4.2) of \(-v\text{;}\) since each vector has a unique vector inverse (Proposition 1.4.14), it will then follow that \((-1)v=-v\text{.}\) To show \((-1)v\) satisfies (1.4.2), we observe that
    \begin{align*} (-1)v+v \amp =(-1)v+1v \amp (\text{Axiom (viii)})\\ \amp = (-1+1)v \amp (\text{Axiom (vii)})\\ \amp =0v\\ \amp = \boldzero (\text{by (1)})\text{.} \end{align*}
    Thus \((-1)v=-v\text{.}\)

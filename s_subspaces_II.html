    Section 1.16 Subspaces: further examples

    Subsection 1.16.1 Important subspaces of \(\ML_{n,n}(F)\)

    In The invertibility theorem we met three families of square matrices: namely, the diagonal, upper triangular, and lower triangular matrices. (See Definition 1.12.3). We now introduce three more naturally occurring families. Before doing so, we give an official definition of the trace function.
    🔗

    Definition 1.16.1. Trace of a matrix.

    Let \(A\in \ML_{n,n}(F)\text{.}\) The trace of \(A\text{,}\) denoted \(\tr A\) is defined as the sum of the diagonal entries of \(A\text{:}\) i.e.,
    \begin{equation*} \tr A=\sum_{i=1}^n [A]_{i,i}\text{.} \end{equation*}
    🔗
    🔗

    Definition 1.16.2. Trace-zero, symmetric, and skew-symmetric.

    Fix an integer \(n\geq 1\text{.}\)
    1. A matrix \(A\in \ML_{n,n}(F)\) is said to be a trace-zero matrix if \(\tr A=0\text{.}\)
      🔗
      🔗
    2. A matrix \(A\in \ML_{n,n}(F)\) is symmetric if \(A^T=A\text{:}\) equivalently, if \([A]_{ij}=[A]_{ji}\) for all \(1\leq i,j\leq n\text{.}\)
      🔗
      🔗
    3. A matrix \(A\in \ML_{n,n}(F)\) is skew-symmetric if \(A^T=-A\text{:}\) equivalently, if \([A]_{ij}=-[A]_{ji}\) for all \(1\leq i,j\leq n\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 1.16.3. Trace-zero symmetric, and skew-symmetric \(2\times 2\) matrices.

    The set \(W_1\) of all trace-zero \(2\times 2\) matrices can be described as
    \begin{equation*} W_1=\left\{ \begin{amatrix}[rr]a\amp b\\ c\amp -a \end{amatrix}\colon a,b,c\in F\right\}\text{.} \end{equation*}
    The set \(W_2\) of all symmetric \(2\times 2\) matrices can be described as
    \begin{equation*} W_2=\left\{ \begin{amatrix}[rr]a\amp b\\ b\amp c \end{amatrix}\colon a,b,c\in F\right\}\text{.} \end{equation*}
    The set \(W_3\) of all skew-symmetric \(2\times 2\) matrices can be described as
    \begin{equation*} W_3=\left\{ \begin{amatrix}[rr]0\amp a\\ -a\amp 0 \end{amatrix}\colon a,b\in F\right\}\text{.} \end{equation*}
    🔗
    🔗

    Remark 1.16.4.

    Assume \(A\) is a skew-symmetric \(n\times n\) matrix. By definition, for all \(1\leq i\leq n\) we must have \([A]_{i,i}=-[A]_{i,i}\text{,}\) or equivalently, \(2[A]_{i,i}=0\text{.}\) If \(2\ne 0\) in our field \(F\text{,}\) it follows that \([A]_{i,i}=0\) for all \(1\leq i\leq n\text{.}\) Thus, in any field where \(2\ne 0\text{,}\) the diagonal entries of a skew-symmetric matrix are all equal to zero.
    🔗
    🔗
    It will come as no surprise that all of the aforementioned matrix families are in fact subspaces of \(M_{n,n}(F)\text{.}\)
    🔗

    Theorem 1.16.5. Matrix subspaces.

    Fix an integer \(n\geq 1\text{.}\) Each of the following subsets of \(M_{n,n}(F)\) is a subspace.
    1. Diagonal matrices.
      \(\displaystyle W=\{A\in M_{n,n}(F)\colon A\text{ is diagonal}\}\)
      🔗
      🔗
    2. Upper triangular matrices.
      \(\displaystyle W=\{A\in M_{n,n}(F)\colon A\text{ is upper triangular}\}\)
      🔗
      🔗
    3. Lower triangular matrices.
      \(\displaystyle W=\{A\in M_{n,n}(F)\colon A\text{ is lower triangular}\}\)
      🔗
      🔗
    4. Trace-zero matrix.
      \(\displaystyle W=\{A\in M_{n,n}(F)\colon \tr A=\boldzero \}\)
      🔗
      🔗
    5. Symmetric matrices.
      \(\displaystyle W=\{A\in M_{n,n}(F)\colon A^T=A \}\)
      🔗
      🔗
    6. Skew-symmetric matrices.
      \(\displaystyle W=\{A\in M_{n,n}(F)\colon A^T=-A \}\)
      🔗
      🔗
    🔗
    🔗

    Proof.

    We will prove only that the set of all skew-symmetric matrices is a subspace. The other proofs are similar. Observe, that once we know that the sets of all upper triangular and lower triangular \(n\times n\) matrices are both subspaces, it follows from Theorem 1.15.6 that the set of all diagonal matrices is a subspace, as this is precisely the intersection of the former two subspaces.
    🔗
    Let \(W=\{A\in\ML_{n,n}(F)\mid A^T=-A\}\text{.}\) We will use the 2-step technique to show \(W\) is a subspace of \(\ML_{n,n}(F)\text{.}\)
    🔗
    First, note that \(\boldzero=\boldzero_{n\times n}\text{,}\) the \(n\times n\) zero matrix, satisfies \(\boldzero_{n\times n}^T=\boldzero_{n\times n}=-\boldzero_{n\times n}\text{.}\) Thus \(\boldzero\in W\text{.}\)
    🔗
    Next, assume \(A,B\in W\text{,}\) so that \(A^T=-A\) and \(B^T=-B\text{.}\) For any \(c,d\in F\text{,}\) we have
    \begin{align*} (cA+dB)^T \amp =cAT^+dB^T \amp (\text{transpose props.})\\ \amp =c(-A)+d(-B) \amp (A,B\in W)\\ \amp =-(cA+dB)\text{,} \end{align*}
    showing that \(cA+dB\in W\text{,}\) as desired.
    🔗
    🔗
    🔗

    Subsection 1.16.2 Power series and formal polynomials

    Our next example involves a little notational slight of hand. Namely, we will introduce the vector space of power series \(F[[x]]\text{,}\) as well as the subspace \(F[x]\) of formal polynomials when in essence \(F[[x]]\) is just the set of \(F^\N\) of infinite \(F\)-valued sequences indexed by \(\N\text{,}\) and \(F[x]\) is really just the subspace of \(F^\N\) consisting of sequences whose entries are zero for all but finally many entries.
    🔗

    Definition 1.16.6. Power series.

    Let \(F\) be a field. The ring of power series with coefficients in \(F\) in the indeterminate \(x\) is the set \(F[[x]]\) consisting of all infinite \(F\)-valued sequences \((a_n)_{n=0}^\infty\text{.}\) In this context, however, a sequence \((a_n)_{n=0}^\infty\) will be written as
    \begin{equation} a_0+a_1x+a_2x^2+\cdots =\sum_{k=0}^\infty a_kx^k\text{.}\tag{1.16.1} \end{equation}
    Given a power series \(\sum_{k=0}^\infty a_kx_k\text{,}\) we call \(a_kx_k\) the \(k\)-th term of the series, and \(a_k\) its \(k\)-th coefficient. We will use function-like notation to denote elements of \(F[[x]]\text{,}\) favoring letters like \(f\text{,}\) \(g\text{,}\) and \(h\text{,}\) and writing \(f(x)=\sum_{k=0}^\infty a_kx^k \) when explicitly introducing the coefficients of \(f\text{.}\)
    🔗
    Since \(F[[x]]\) is equal to \(F^\N\) but with a different choice of notation, it inherits the notion of equality of \(F^\N\text{,}\) as well as its vector space structure. That is given any power series \(f(x)=\sum_{k=0}^\infty a_kx^k\) and \(g(x)=\sum_{k=0}^\infty b_kx^k\) and any scalar \(c\in F\text{,}\) we have
    \begin{align*} f=g \amp \iff a_k=b_k \text{ for all } k\in \N\\ (f+g)(x) \amp =\sum_{k=0}^\infty (a_k+b_k)x^k\\ (cf)(x) \amp =\sum_{k=0}^\infty ca_k x^k\text{.} \end{align*}
    As an additional layer of algebraic structure, we define the product of two power series \(f(x)=\sum_{k=0}^\infty a_kx^k\) and \(g(x)=\sum_{k=0}^\infty b_kx^k\) as follows:
    \begin{align} (fg)(x) \amp =\sum_{k=0}^\infty c_kx^k \amp c_k=\sum_{j=0}^ka_jb_{k-j} \text{ for all } k\in \N\text{.}\tag{1.16.2} \end{align}
    🔗
    🔗

    Remark 1.16.7. Power series multiplication.

    Power series multiplication, that extra layer of structure mentioned above, can be thought of as the motivation for using our notation \(f(x)=\sum_{k=0}^\infty a_kx^k\text{,}\) as opposed to the usual tuple notation \((a_k)_{k\in \N}\text{.}\) For one thing, identifying \(x^n\) as the power series with a 1 for the \(n\)-th coefficient and a zero elsewhere, it is easy to see that the power series multiplication rule implies \(x^n\cdot x^m=x^{n+m}\) for all \(n,m\in \N\text{.}\) General power series multiplication can then be understood as a sort of infinite “foiling” process, where we expand a product out via distribution, collect like terms, and then distribute again:
    \begin{align*} fg\amp =(a_0+a_1x+a_2x^2+\cdots )(b_0+b_1x+b_2x^2+\cdots)\\ \amp = a_0b_0+(a_0b_1+a_1b_0)x+(a_0b_2+a_1b_1+a_2b_0)x^2+\cdots \end{align*}
    🔗
    🔗

    Remark 1.16.8. Properties of power series multiplication.

    It is easy to prove that power series multiplication is commutative, associative, and distributive. In more detail, for any \(f,g,h\in F[[x]]\text{,}\) we have
    \begin{align*} fg \amp =gf \amp f(gh)\amp=(fg)h \amp f(g+h) \amp =(g+h)f =fg+fh\text{.} \end{align*}
    Furthermore, we identify \(F\) as a subset of \(F[[x]]\) by identifying a scalar \(c\in F\) with the power series \(c=c+0x+0x^2+\cdots\text{.}\) Note that we have
    \begin{align*} (c+0x+0x^2+\cdots)+(d+0x+0x^2+\cdots) \amp = (c+d)+0x+0x^2+\cdots +c+0x+0x^2+\cdots\\ (c+0x+0x^2+\cdots)(d+0x+0x^2+\cdots) \amp = cd+0x+0x^2+\cdots\text{,} \end{align*}
    showing that this identification of \(F\) as a subset of \(F[[x]]\) preserves the notions of addition and multiplication on \(F\text{.}\)
    🔗
    🔗
    We now define the set of formal polynomials \(F[x]\) as the subspace of \(F[[x]]\) consisting of all power series whose coefficients are equal to zero for all but finitely many indices.
    🔗

    Definition 1.16.9. Formal polynomials.

    Let \(F\) be a field. Define the polynomial ring over \(F\) in the indeterminate \(x\) to be the subset \(F[x]\subseteq F[[x]]\) of all power series whose coefficients are equal to zero for all but finitely many indices: i.e.,
    \begin{align*} F[x] \amp = \{f(x)=\sum_{n=0}^\infty a_nx^n\in F[[x]]\mid a_n=0 \text{ for all } n> N \text{ for some } N\in \Z_{\geq 0} \} \\ \amp =\{f\in F[[x]]\mid f(x)=\sum_{n=0}^Na_nx^n \text{ for some } N\in \Z_{\geq 0}, a_n\in F\}\text{.} \end{align*}
    Restricted to \(F[x]\text{,}\) the power series multiplication rule becomes the familiar polynomial multiplication rule:
    \begin{align} (\anpoly)\amp \cdot (\bmpoly) =\sum_{k=0}^{m+n}c_kx^k\tag{1.16.3}\\ c_k\amp =\sum_{j=0}^k a_j b_{k-j}\text{.}\tag{1.16.4} \end{align}
    As illustrated above, when denoting polynomials we will usually drop all the terms with zero coefficients: e.g., \(f(x)=a_0+a_1x+\cdots +a_nx^n\text{,}\) or \(f(x)=\anpoly\text{.}\)
    🔗
    Given a nonzero polynomial \(f\in F[x]\text{,}\) we define its degree, \(\deg f\text{,}\) to be the largest \(n\) satisfying \(a_n\ne 0\text{.}\) If \(f = \boldzero\text{,}\) we define \(\deg f=-\infty\text{.}\)
    🔗
    If \(f(x)=\anpoly\) is a polynomial of degree \(n\ne -\infty\text{,}\) we call \(a_{n}\) the leading coefficient of \(f\text{.}\) A polynomial with leading coefficient equal to \(1\in R\) is called monic.
    🔗
    🔗

    Definition 1.16.10. Polynomials of bounded degree.

    Let \(F\) be a field. Given \(n\in \N\text{,}\) we define \(F[x]_{\deg \leq n}\) to be the set of polynomials of \(F[x]\) of degree at most \(n\text{:}\) i.e.,
    \begin{equation*} F[x]_{\deg \leq n}=\{f\in F[x]\mid \deg f\leq n\}. \end{equation*}
    Note that the zero polynomial \(\boldzero\) is understood to be an element of \(F[x]_{\deg\leq n}\) based on the convention that \(\deg \boldzero=-\infty< n\) for all \(n\in \N\text{.}\)
    🔗
    🔗
    Not surprisingly, the nested sets \(F[x]_{\deg\leq n}\subseteq F[x]\subseteq F[[x]]\) are all subspaces of one another.
    🔗

    Proposition 1.16.11.

    Let \(F\) be a field and let \(n\in \N\text{.}\) The inclusions
    \begin{equation*} F[x]_{\deg\leq n}\subseteq F[x]\subseteq F[[x]] \end{equation*}
    are subspace inclusions: i.e., in the chain above, each set is a subspace of the next.
    🔗
    🔗

    Proof.

    The proof is left to the reader.

    🔗
    Besides being used to define an interesting subspace of \(F[x]\) and \(F[[x]]\text{,}\) the degree function will prove to be important to us in many ways, as the next results begin to show.
    🔗
    The degree operation on \(F[x]\) turns out to be very useful, thanks in part to the properties articulated in the following proposition.
    🔗

    Proposition 1.16.12. Polynomial degree properties.

    Let \(F\) be a field, and let \(f\) and \(g\) be nonzero polynomials in \(F[x]\text{.}\)
    1. \(\deg fg=\deg f+\deg g\text{.}\)
      🔗
      🔗
    2. \(\deg(f+g)\leq \max\{\deg f, \deg g\}\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.

    1. Assume \(\deg f=n\) and \(\deg g=m\text{,}\) so that
      \begin{align*} f(x) \amp =\anpoly \amp \\ g(x)\amp=\bmpoly \amp \text{,} \end{align*}
      where \(a_n\ne 0\) and \(b_m\ne 0\text{.}\) From the polynomial multiplication rule given in (1.16.3), we see that
      \begin{align*} fg(x) \amp =a_nb_mx^{n+m}+\text{terms of lower degree}\text{.} \end{align*}
      It follows that \(\deg fg\leq n+m=\deg f+\deg g\text{.}\) If \(F\) is an integral domain, then \(a_nb_m\ne 0\) and thus \(\deg fg=m+n=\deg f+\deg g\text{.}\)
      🔗
      🔗
    2. The proof is left to the reader.
      🔗
      🔗

    Definition 1.16.14. Roots of polynomials.

    Let \(F\) be a field. Given a polynomial \(f(x)=\anpoly\in F[x]\) and element \(r\in F\text{,}\) we define
    \begin{equation*} f(r)=a_nr^n+a_{n-1}r^{n-1}+\cdots a_1r+a_0\in F\text{.} \end{equation*}
    An element \(r\in F\) is a root of \(f\) if \(f(r)=0\text{.}\)
    🔗
    🔗

    Corollary 1.16.15. Distinct roots of polynomials.

    Let \(F\) be a field, and let \(f\in F[x]\text{.}\)
    1. For all \(r\in F\text{,}\) we have \(f(r)=0\) if and only if \(f=(x-r)g(x)\) for some polynomial \(g\in F[x]\text{.}\)
      🔗
      🔗
    2. Assume \(f\ne \boldzero\text{.}\) If \(\deg f=n\text{,}\) then \(f\) has at most \(n\) distinct roots.
      🔗
      🔗
    3. Assume \(n\in \N\text{,}\) and that \(f,g\in F[x]\) satisfy \(\deg f=\deg g=n\text{.}\) If there are \(n+1\) distinct elements \(r_1,r_2,\dots, r_{n+1}\in F\) such that \(f(r_i)=g(r_i)\text{,}\) then \(f=g\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.

    Subsection 1.16.3 Function spaces

    Definition 1.16.16. Polynomial functions.

    Let \(F\) be a field, and let \(I\) be a nonempty subset of \(F\text{.}\) A function \(f\in \mathcal{F}(I,F)\) is a polynomial function if there is a formal polynomial \(g\in F[x]\) such that \(f(x)=g(x)\) for all \(x\in I\text{.}\) We say that the polynomial \(g\) represents \(f\) in this case.
    🔗
    We define \(P(I)\) to be the set of all polynomial functions on \(I\text{,}\) and we define \(P_n(I)\) to the set of all functions \(f\in \mathcal{F}(I,F)\) that can be represented by a polynomial of degree at most \(n\text{:}\) i.e.,
    \begin{align*} P(I) \amp =\{f\in \mathcal{F}(I,F)\mid f(x)=g(x) \text{ for all } x\in I, \text{ for some } g\in F[x]\}\\ P_n(I) \amp =\{f\in \mathcal{F}(I,F)\mid f(x)=g(x) \text{ for all } x\in I, \text{ for some } g\in F[x]_{\deg\leq n}\}\text{.} \end{align*}
    🔗
    🔗

    Remark 1.16.17. Formal polynomials and polynomial functions.

    There is a subtle issue lurking behind this polynomial function business: namely, it is possible that a polynomial function \(f\in P(I)\) can be represented by more than one formal polynomial \(g\in F[x]\text{.}\) Indeed, consider the case where the subset \(I\subseteq F\) is the singleton \(I=\{1\}\text{.}\) In this case, any function \(f\in \mathcal{F}(I,F)\) is completely determined by its value \(f(1)=c\) at the one element of the domain \(I\text{.}\) As a result, it is possible to give many different polynomial representation of a single function \(f\text{.}\) For example, the zero function \(0_I\) can be represented by the zero polynomial \(\boldzero\text{,}\) but also by \(f(x)=(x-1)^n\) for any \(n\in \Z_+\text{.}\) We see then, that we do not always have a 1-1 correspondence between elements of \(F[x]\) and \(P(I)\text{.}\) We will be able to give a much more precise analysis of the relationship between these two spaces once we introduce linear transformations.
    🔗
    🔗

    Proposition 1.16.18. Polynomial spaces.

    Let \(I\) be a nonempty subset of the field \(F\text{.}\)
    1. \(P(I)\) is a subspace of \(\mathcal{F}(I,F)\text{.}\)
      🔗
      🔗
    2. \(P_n(I)\) is a subspace of \(\mathcal{F}(I,F)\) for all \(n\in \N\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.

    We prove that \(P_n(I)\) is a subspace, using the 2-step technique. The proof for \(P(I)\) is similar.
    1. Recall that the zero vector of \(\mathcal{F}(I,F)\) is the the zero function \(O_I\colon I\rightarrow F\text{,}\) defined as \(0_I(x)=0\) for all \(x\in I\text{.}\) Writing
      \begin{equation*} 0_I(x)=0x^n+0x^{n-1}+\cdots +0x+0\text{,} \end{equation*}
      we see that \(\boldzero=0_I\in P_n(I)\text{.}\) (More generally, any constant function \(f(x)=c\) is an element of \(P_n(I)\) for all \(n\geq 0\text{.}\))
      🔗
      🔗
    2. Assume \(f,g\in P_n(I)\text{.}\) By definition this means that there are constants \(a_i, b_i\in F\text{,}\) \(1\leq i\leq n\text{,}\) such that
      \begin{align*} f(x) \amp = \anpoly\\ g(x) \amp = b_nx^n+b_{n-1}x^{n-1}+\cdots+b_1x+b_0 \end{align*}
      for all \(x\in I\text{.}\) It follows that
      \begin{align*} (cf+dg)(x) \amp = (a_n+b_n)x^n+(a_{n-1}+b_{n-1})x^{n-1}+\cdots+(a_1+b_1)x+(a_0+b_0) \end{align*}
      for all \(x\in I\text{,}\) showing that \(cf+dg\in P_n(I)\text{,}\) as desired.
      🔗
      🔗
    🔗
    🔗

    Definition 1.16.19. Function subspaces over \(\R\).

    Let \(I\) be an interval of \(\R\) that contains at least two elements.
    1. We denote by \(C(I)\) the set of all continuous functions on \(I\text{:}\) i.e.,
      \begin{equation*} C(I)=\{f\in \R^I\colon f \text{ is continuous on }I\}\text{.} \end{equation*}
      🔗
      🔗
    2. Fix \(n\geq 1\text{.}\) A function \(f\colon I\rightarrow \R\) is \(C^{n}\) on \(I\) if \(f\) is \(n\)-times differentiable on \(I\) and its \(n\)-th derivative \(f^{(n)}(x)\) is continuous. The set of all \(C^{n}\) functions on \(I\) is denoted \(C^{n}(I)\text{.}\)
      🔗
      🔗
    3. A function \(f\colon I\rightarrow \R\) is \(C^{\infty}\) on I if \(f\) is infinitely differentiable on \(I\text{.}\) The set of all \(C^{\infty}\) functions on \(I\) is denoted \(C^{\infty}(I)\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Theorem 1.16.20. Function subspaces..

    Let \(I\subseteq \R\) be a an interval containing at least two elements. The sets \(C(I)\text{,}\) \(C^{n}(I)\text{,}\) \(C^{\infty}(I)\text{,}\) \(P(I)\text{,}\) \(P_{n}(I)\) are all subspaces of \(\mathcal{F}(I,\R)\text{,}\) and we have the following chain of subspaces:
    \begin{equation*} P_{n}(I)\subseteq P(I)\subseteq C^{\infty}(I)\subseteq C^{n}(I)\subseteq C(I)\subseteq \mathcal{F}(I,\R)\text{.} \end{equation*}
    🔗
    🔗

    Proof.

    This is an instance of “proof by calculus”. That each of these sets is closed under addition and scalar multiplication follows from elementary results in single-variable calculus: e.g., that sums and scalar multiples of continuous functions are continuous, that sums and scalar multiples of differentiable functions are differentiable, etc..

    Section 1.5 Vector space of \(n\)-tuples

    Subsection 1.5.1 \(n\)-tuples

    Definition 1.5.1. \(F\)-valued \(n\)-tuples.

    Let \(F\) be a field, and let \(n\) be a positive integer. An \(F\)-valued \(n\)-tuple is a function \(f\colon \{1,2,\dots, n\}\rightarrow F\text{.}\) In this setting, we will use an alternative tuple notation, writing
    \begin{equation*} f=(a_i)_{i=1}^n=(a_1,a_2,\dots, a_n)\text{,} \end{equation*}
    where \(a_i=f(i)\text{,}\) the value of \(f\) at \(i\text{,}\) for all \(i\in \{1,2,\dots, n\}\text{.}\) We will also favor letters like \(v,w,u\) to denote \(n\)-tuples, as opposed to \(f,g,h\text{.}\)
    🔗
    Given an \(n\)-tuple \(v=(a_i)_{i=1}^n\text{,}\) we call \(n\) the length of \(v\text{,}\) and for each index \(i\in \{1,2,\dots, n\}\text{,}\) we call \(a_i\) the \(i\)-th component (or coordinate, or entry, or term) of \(v\text{.}\)
    🔗
    The set of all \(F\)-valued \(n\)-tuples is denoted \(F^n\text{:}\) i.e.,
    \begin{equation*} F^n=\{(a_i)_{i=1}^n\mid a_i\in \F \text{ for all } i=1,2,\dots, n\}\text{.} \end{equation*}
    🔗
    🔗
    Observe that by definition, \(F^n\) is just a special instance of our function space construction \(\mathcal{F}(X,F)\text{.}\) In more detail, an \(n\)-tuple \((a_i)_{i=1}^n\) is by definition a function \(f\colon \{1,2,\dots, n\}\rightarrow F\) defined as \(f(i)=a_i\) for all \(1\leq i\leq n\text{,}\) and thus the set \(F^n\) is precisely the function space \(\mathcal{F}(I, F)\text{,}\) where \(I=\{1,2,\dots, n\}\text{.}\) As a first convenient consequence of this fact, our definition of \(n\)-tuples comes equipped with a well-defined notion of equality from their fundamental nature as functions: namely, we have
    \begin{equation*} (a_1,a_2,\dots, a_n)=(b_1,b_2,\dots, b_n) \end{equation*}
    if and only if \(a_i=b_i\) for all \(1\leq i\leq n\text{.}\) In other words, our rigorous notions of \(n\)-tuples captures the often casually introduced notion of an ordered sequence. We record this as an official fact to make this prominent.
    🔗

    Proposition 1.5.2. \(n\)-tuple equality.

    Let \(F\) be a field, and let \(n\) be a positive integer. Given \(v=(a_i)_{i=1}^n, w=(b_i)_{i=1}^n\in F^n\text{,}\) we have
    \begin{equation} v=w \text{ if and only if } a_i=b_i \text{ for all } i\in \{1,2,\dots, n\}\text{.}\tag{1.5.1} \end{equation}
    🔗
    🔗
    Another consequence of \(F^n\) being defined as \(\mathcal{F}(I,F)\) for \(I=\{1,2,\dots, n\}\text{,}\) is that, thanks to Theorem 1.4.11, \(F^n\) automatically inherits the structure of a vector space. The theorem below makes this explicit, and rearticulates the function addition and scalar multiplication operations using tuple notation.
    🔗

    Theorem 1.5.3. \(F^n\) vector space structure.

    Let \(F\) be a field, and let \(n\) be a positive integer. The set \(F^n\) of all \(F\)-valued \(n\)-tuples is a vector space with respect to the operations defined as
    \begin{align*} (a_i)_{i=1}^n+(b_i)_{i=1}^n\amp =(a_i)_{i=1}^n+(b_i)_{i=1}^n \\ c(a_i)_{i=1}^n\amp =(ca_i)_{i=1}^n \end{align*}
    for all \((a_i)_{i=1}^n, (b_i)_{i=1}^n\in F^n\) and \(c\in F\text{.}\)

    Definition 1.5.4. Special elements of \(F^n\).

    Let \(F\) be a field, and let \(n\) be a positive integer.
    • Zero vector.
      The zero vector of \(F^n\text{,}\) denoted \(\boldzero_n\) (or \(\boldzero\) for short), is the \(n\)-tuple, all of whose entries are equal to \(0\text{:}\) i.e., \(\boldzero_n=(0)_{i=1}^n\text{.}\)
      🔗
      🔗
    • Vector inverse.
      Given an \(n\)-tuple \(v=(a_i)_{i=1}^n\in F^n\text{,}\) the vector inverse of \(v\text{,}\) denoted \(-v\text{,}\) is the element of \(F^n\) defined as
      \begin{equation*} -v=(-a_i)_{i=1}^n\text{.} \end{equation*}
      🔗
      🔗
    • Indicator vectors.
      For each \(i\in \{1,2,\dots, n\}\text{,}\) the \(i\)-th standard basis element of \(F^n\text{,}\) denoted \(\bolde_i\text{,}\) is the \(n\)-tuple whose \(i\)-th entry is equal to \(1\) and whose \(j\)-th entry is equal to \(0\) for all \(j\ne i\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Definition 1.5.5. Linear combination.

    Let \(V\) be a vector space, and let \(S\) be a nonempty subset of \(V\text{.}\) A linear combination of \(S\) is a vector of the form
    \begin{equation} c_1v_1+c_2v_2+\cdots +c_nv_n\text{,}\tag{1.5.2} \end{equation}
    where \(v_i\in S\) and \(c_i\in \R\) for all \(1\leq i\leq n\text{.}\) The scalars \(c_i\) appearing in (1.5.2) are called the coefficients of the linear combination. The linear combination (1.5.2) is trivial if \(c_i=0\) for all \(1\leq i\leq n\text{,}\) and nontrivial if \(c_i\ne 0\) for some \(1\leq i\leq n\text{.}\)
    🔗
    In the special case where \(S\) is described enumeratively as \(S=\{v_1,v_2,\dots, v_n\}\) or \(S=\{v_1,v_2,\dots\}\text{,}\) we will call a linear combination of \(S\) a linear combination of the \(v_i\) for short.
    🔗
    We will sometimes use sigma notation for linear combinations, writing
    \begin{equation*} \sum_{i=1}^nc_iv_i \end{equation*}
    for the linear combination of the vectors \(v_1,v_2,\dots, v_n\) whose \(i\)-th coefficient is \(c_i\text{.}\)
    🔗
    🔗

    Example 1.5.6. Linear combination: \(n\)-vectors.

    Show that every vector in \(F^3\) is a linear combination of the standard basis vectors \(\bolde_1\text{,}\) \(\bolde_2\text{,}\) and \(\bolde_3\text{.}\)
    🔗
    Solution.
    Given any vector \(v=(a,b,c)\in F^3\text{,}\) we have
    \begin{align*} v\amp =a\bolde_1+b\bolde_2+c\bolde_3 \text{.} \end{align*}
    🔗
    🔗
    🔗

    Definition 1.5.7. Vector difference.

    Let \(V\) be a vector space. Given vectors \(v,w\in V\text{,}\) we define their difference \(v-w\) as
    \begin{equation*} v-w=v+(-w)\text{.} \end{equation*}

    Subsection 1.5.2 Visualizing \(\R^n\)

    We will only explicitly visualize (or graph) elements of \(\R^n\) for \(n=2\) and \(n=3\text{.}\) However, these special cases bring to light an important point-vector duality in how we conceive of \(n\)-tuples that carries over into higher values of \(n\text{.}\) Fix \(n=3\) for now. We will sometimes conceive of a triple \((a,b,c)\in \R^3\) as a point, in which case we will use capital letters to denote the triple (e.g., \(P=(a,b,c)\)), and will represent the point visually with respect to a coordinate system as the point in \(3\)-space reached by starting at the origin \(O=(0,0,0)\) and moving a directed distance \(a\) units in the \(x\)-direction, \(b\) units in the \(y\)-direction and \(c\) units in the \(z\)-direction.
    🔗
    Alternatively, when conceiving of a triple \((a,b,c)\) as a vector, we will use lowercase bold letters to denote it (e.g., \(\boldx=(a,b,c)\) or \(\boldv=(a,b,c)\)), and represent it visually as a directed line segment (i.e., an arrow). In more detail, given the 3-vector \(\boldx=(a,b,c)\text{,}\) we choose an initial point \(Q=(x_0,y_0,z_0)\) and represent \(\boldx\) as the directed line segment \(\overrightarrow{QR}\) that starts at \(Q\) and ends at the point \(R=(x_0+a,y_0+b,z_0+c)\text{,}\) the terminal point of \(\overrightarrow{QR}\text{.}\) Note that in this manner we get infinitely-many different graphical representations of \(\boldx\text{:}\) one for each choice of starting point \(Q\text{.}\) Although these are technically different arrows (they have different starting points), we consider them to be equal as vectors. You can think of each particular choice of arrow-representation \(\boldx=\overrightarrow{QR}\) as an instance or incarnation of the vector \(\boldx=(a,b,c)\text{.}\) When the initial point of our arrow representation is chosen to be the origin \(O=(0,0,0)\text{,}\) we have \(\boldx=\overrightarrow{OP}\text{,}\) where \(P=(a,b,c)\text{.}\) We call \(\overrightarrow{OP}\) the position vector of the point \(P\text{.}\)
    🔗
    The representation of vectors as arrows gives rise to the so-called tip-to-tail interpretation of vector addition. Let \(\boldx=(a,b,c)\) and \(\boldy=(d,e,f)\text{.}\) Starting with an initial point \(P=(x_0,y_0,z_0)\text{,}\) we can represent \(\boldx\) as \(\overrightarrow{PQ}\text{,}\) where \(Q=(x_0+a,y_0+b,z_0+c)\text{,}\) and \(\boldy=\overrightarrow{QR}\text{,}\) where \(R=(x_0+a+d,y_0+b+e,z_0+c+f)\text{.}\) But then we have
    \begin{equation*} \boldx+\boldy=(a+d,b+e,c+f)=\overrightarrow{PR}\text{,} \end{equation*}
    or alternatively,
    \begin{equation} \overrightarrow{PQ}+\overrightarrow{QR}=\overrightarrow{PR}\text{.}\tag{1.5.3} \end{equation}
    In other words, if we choose our arrow representations so that the terminal point (the tip) of \(\boldx=\overrightarrow{PQ}\) is placed at the initial point (the tail) of \(\boldy=\overrightarrow{QR}\) , then \(\boldx+\boldy\) is represented by the arrow whose initial point is \(P\text{,}\) and whose terminal point is reached by first traveling along \(\boldx\text{,}\) and then traveling along \(\boldy\text{.}\)
    🔗
    The tip-to-tail visualization of vector addition gives rise to a similar conceptualization of vector difference. Performing a little vector algebra on the definition
    \begin{equation*} \boldy-\boldx=\boldy+ (-\boldx)\text{,} \end{equation*}
    we see that
    \begin{equation*} \boldx+(\boldy-\boldx)=\boldy\text{.} \end{equation*}
    Using tip-to-tail terminology, this means if we represent \(\boldx=\overrightarrow{PQ}\) and \(\boldy=\overrightarrow{PR}\text{,}\) then \(\boldy-\boldx\) is the arrow \(\overrightarrow{QR}\) that starts at the tip of \(\boldx\) and ends at the tip of \(\boldy\text{.}\) We thus have a tip-to-tip description of vector difference.
    🔗
    Next consider scalar multiplication. Given a vector \(\boldx=(a,b,c)=\overrightarrow{PQ}\) and a scalar \(k\in \R\text{,}\) the scalar multiple \(k\boldx=(ka,kb,kc)\) can be represented as an arrow that starts at \(P\) and points along the line containing \(\overrightarrow{PQ}\text{.}\) As we will see in the next section, the length of the resulting arrow is multiplied by the factor \(\abs{k}\text{,}\) resulting in a stretched arrow if \(\abs{k}> 1\) and a shrunk arrow if \(\abs{k}< 1\text{.}\) Furthermore, if \(k\geq 0\text{,}\) then the arrow representing \(k\boldx\) points in the same direction as \(\overline{PQ}\text{;}\) if \(k< 0\text{,}\) it points in the opposite direction.

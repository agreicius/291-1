    Section 1.21 Isomorphisms

    The word “isomorphism” is derived from the Greek terms iso, meaning “same”, and morphe, meaning “form”. As we will see, two isomorphic vector spaces \(V\) and \(W\) are essentially the same creature, at least as far as linear algebraic properties are concerned. Furthermore, an isomorphism \(T\colon V\rightarrow W\) provides a one-to-one correspondence between them: a dictionary that allows us to translate statements about \(V\) to statements about \(W\text{,}\) and vice versa.
    🔗
    The definition of an isomorphism will involve the function composition operation. As such, we begin with some notational conventions and elementary properties of compositions of linear maps.
    🔗

    Convention 1.21.1 Composition of linear transformations.

    Given linear transformations \(T\colon U\rightarrow V\) and \(S\colon V\rightarrow W\text{,}\) we will occasionally denote their composition \(S\circ T\colon U\rightarrow W\) as \(ST\text{.}\)
    🔗
    🔗

    Theorem 1.21.2 Composition of linear transformations.

    Let \(T,T_1,T_2\in \mathcal{L}(U,V)\text{,}\) \(S,S_1,S_2\in \mathcal{L}(V,W)\text{,}\) and \(R\in \mathcal{L}(W,W')\text{.}\)
    1. The composition \(S\circ T\colon U\rightarrow W\) is a linear transformation.
      🔗
      🔗
    2. \(\displaystyle R\circ(S\circ T)=(R\circ S)\circ T\)
      🔗
      🔗
    3. \(S\circ(T_1+T_2)=S\circ T_1+S\circ T_2\) and \((S_1+S_2)\circ T=S_1\circ T+S_2\circ T\text{.}\)
      🔗
      🔗
    4. \(T\circ \id_U=T\) and \(\id_V\circ T=T\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    The proofs of (2)-(4) follow pretty much directly from the definitions of the function operations involved and basic set-theoretic properties of functions and their compositions. As such we content ourselves with a proof only of (1). Assume \(T\in\mathcal{L}(U,V)\) and \(S\in \mathcal{L}(V,W)\text{.}\) We use the one-step technique to show the composition \(S\circ T\colon U\rightarrow W\) is linear. Given any \(v,v'\in V\) and scalars \(c,d\in F\text{,}\) we have
    \begin{align*} S\circ T(cv+dv') \amp = S(T(cv+dv')) \amp (\text{def. of comp.})\\ \amp =S(cT(v)+dT(v')) \amp (T \text{ linear}) \\ \amp = cS(T(v))+dS(T(v')) \amp (S \text{ linear})\\ \amp =cS\circ T(v)+dS\circ T(v')\text{.} \end{align*}
    🔗
    🔗

    Definition 1.21.3 Isomorphism.

    A linear map \(T\in \mathcal{L}(V,W)\) is an isomorphism if there is a linear transformation \(S\in \mathcal{L}(W,V)\) satisfying \(S\circ T=\id_V\) and \(T\circ S=\id_W\text{.}\) When this is the case we call \(S\) the inverse of \(T\text{,}\) and write \(S=T^{-1}\text{.}\) Two vector spaces \(V\) and \(W\) are isomorphic if there is an isomorphism \(T\colon V\rightarrow W\text{.}\)
    🔗
    🔗

    Remark 1.21.4 Inverse functions.

    Using the language of inverse functions, we see that a linear transformation \(T\colon V\rightarrow W\) is an isomorphism if (a) it is invertible, and (b) its inverse \(T^{-1}\colon W\rightarrow V\) is itself a linear transformation. As we will see in the next theorem, this second condition is automatic.
    🔗
    🔗

    Theorem 1.21.5 Isomorphisms.

    Let \(T\in \mathcal{L}(V,W)\text{.}\) The following statements are equivalent.
    1. \(T\) is an isomorphism.
      🔗
      🔗
    2. \(T\) is invertible.
      🔗
      🔗
    3. \(T\) is bijective.
      🔗
      🔗
    🔗
    🔗

    Proof.
    The implication (1)\(\implies\)(2) follows directly from the definition. Furthermore, the equivalence (2)\(\iff\)(3) is a purely set-theoretic result relating invertible and bijective functions. It remains then only to show that (2)\(\implies\)(1): i.e., that if \(T\) is linear and invertible, then its inverse \(T^{-1}\) is itself linear.
    🔗
    Assume \(T\) is linear and invertible. We will use the one-step technique to prove \(T^{-1}\) is linear. First, given any \(w,w'\in W\text{,}\) since \(T\) and \(T^{-1}\) are inverses of one another, there are vectors \(v,v'\in V\) satisfying
    \begin{align*} T(v) \amp =w \amp T^{-1}(w)\amp= v\\ T(v') \amp =w' \amp T^{-1}(w')\amp= v'\text{.} \end{align*}
    It then follows that given any scalars \(c,d\in F\text{,}\) we have
    \begin{align*} T^{-1}(cw+dw') \amp = T^{-1}(cT(v)+dT(v'))\\ \amp =T^{-1}(T(cv+dv')) \amp (T \text{ linear})\\ \amp =cv+dv' \amp (T^{-1}T=I_V)\\ \amp =cT^{-1}(w)+dT^{-1}(w')\text{.} \end{align*}
    🔗
    🔗
    The equivalences in Theorem 1.21.5 give us a number of potential approaches to deciding whether a linear transformation is an isomorphism, as we detail in the next procedure.
    🔗

    Procedure 1.21.6 Isomorphisms.

    Assume \(T\colon V\rightarrow W\) is a linear transformation. Below you find three separate approaches for deciding whether \(T\) is an isomorphism. Depending on the context, one approach may be more convenient than the others.
    1. Invertibility.
      Provide an inverse function \(T^{-1}\colon W\rightarrow V\text{,}\) or prove that no such inverse function exists. By Theorem 1.21.5, an inverse function is automatically linear.
      🔗
      🔗
    2. Bijection.
      Determine whether \(T\) is bijective. This can be accomplished by computing \(\NS T\) and \(\im T\text{.}\)
      🔗
      🔗
    3. \(\dim V=\dim W< \infty\).
      If \(\dim V=\dim W< \infty\text{,}\) then the following statements are equivalent.
      1. \(T\) is an isomorphism.
        🔗
        🔗
      2. \(T\) is injective (equivalently, \(\NS T=\{\boldzero\}\)).
        🔗
        🔗
      3. \(T\) is surjective (equivalently, \(\Im T=W\)).
        🔗
        🔗
      🔗
      🔗
    🔗
    🔗

    Example 1.21.7 Transposition.

    Define \(S\colon \ML_{m,n}\rightarrow \ML_{n,m}\) as \(S(A)=A^T\text{.}\) Prove that \(S\) is an isomorphism.
    🔗
    Solution.
    We saw in Example 1.19.15 the the transposition operation is linear. To show it is an isomorphism, we produce an inverse. Define \(S^{-1}\colon \ML_{n,m}\rightarrow \ML_{m,n}\) as \(S^{-1}(B)=A^T\text{.}\) (Note that even though the rule for \(S^{-1}\) is the same as that for \(S\) (i.e., take the transpose), we do not necessarily have \(S=S^{-1}\) as functions since their domains (and codomains) are not necessarily equal.) We have
    \begin{align*} S\circ S^{-1}(B) \amp =S(B^T)=(B^T)^T=B \text{ for all } B\in \ML_{n,m}\\ S^{-1}\circ S(A) \amp =S^{-1}(A^T)=(A^T)^T=A \text{ for all } A\in \ML_{m,n}\text{,} \end{align*}
    proving that the two maps are indeed inverses of one another. We conclude that \(S\) is invertible, and hence an isomorphism.
    🔗
    🔗
    🔗

    Example 1.21.8 Formal polynomials and polynomial functions.

    Let \(I\) be a subset of the field \(F\text{.}\) The function \(T\colon F[x]\rightarrow P(I)\) that defines \(T(f)\) to be the function on \(I\) represented by \(f\) is a linear transformation.
    1. Prove: \(T\) is surjective.
      🔗
      🔗
    2. Prove: \(T\) is injective if and only if \(I\) is infinite.
      🔗
      🔗
    3. The restriction \(S=T\vert_{F[x]_{\deg \leq n}}\) of \(T\) to the subspace \(F[x]_{\deg\leq n}\) defines a linear transformation \(S\colon F[x]_{\deg\leq n}\rightarrow P_n(I)\text{.}\)
      🔗
      Prove: \(S\) is an isomorphism if and only if \(\abs{I}\geq n+1\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    🔗
    🔗
    🔗

    Example 1.21.9 Evaluation.

    Let \(c_1,c_2,\dots, c_{k}\) be \(n+1\) distinct scalars of the field \(F\) and define \(T\colon F_{\deg\leq n}[x]\rightarrow F^{k}\) as \(T(f)=(f(c_i))_{i=1}^k\text{.}\)
    1. Prove: \(T\) is a linear transformation.
      🔗
      🔗
    2. Prove: \(T\) is in injective if and only if \(k\geq n+1\text{.}\)
      🔗
      🔗
    3. Prove: \(T\) is surjective if and only if \(k\leq n+1\text{.}\)
      🔗
      🔗
    4. Prove: \(T\) is an isomorphism if and only if \(k=n+1\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    We showed in Example 1.20.8 that this linear transformation is bijective, and hence an isomorphism.
    🔗
    🔗
    🔗

    Theorem 1.21.10 Isomorphisms preserve structure.

    Let \(T\colon V\rightarrow W\) be an isomorphism.
    1. A tuple \(S=(v_i)_{i\in I}\) of vectors in \(V\) is linearly independent if and only if its image \(T(S)=(T(v_i))_{i\in I}\) is linearly independent.
      🔗
      🔗
    2. Let \(W=\Span S\text{,}\) where \(S=(v_i)_{i\in I}\) is a tuple in \(V\text{.}\) We have
      \begin{equation} T(W)=T(\Span S)=\Span T(S)=\Span (T(v_i))_{i\in I}\text{.}\tag{1.21.1} \end{equation}
      🔗
      🔗
    3. \(B=(v_i)_{i\in I}\) is a basis of \(V\) if and only if \(T(B)=(T(v_i))_{i\in I}\) is a basis of \(W\text{.}\)
      🔗
      🔗
    4. \(V\) is finite-dimensional if and only if \(W\) is finite-dimensional, and in this case we have \(\dim V=\dim W\text{.}\)
      🔗
      🔗
    5. \(U\) is a subspace of \(V\) if and only if \(T(U)\) is a subspace of \(W\text{.}\)
      🔗
      🔗
    6. We have \(V=V_1\oplus V_2\) for subspaces \(V_i\subseteq V\) if and only if \(W=T(V_1)\oplus T(V_2)\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    Most of the statements of this theorem follow almost immediately from the observation that since \(T\) is an isomorphism we have
    \begin{equation*} \sum_{i\in I}c_iv_i=v \iff \sum_{i\in I}c_iT(v_i)=T(v) \end{equation*}
    for any linear combination expression \(\sum_{i\in I}c_iv_i=v\) in \(V\text{,}\) along with the analogous statement for \(T^{-1}\text{.}\) Thus, for example, we have
    \begin{align*} w\in T(\Span S) \amp \iff w=T(v) \text{ for some } v\in \Span S\\ \amp \iff w=T(\sum_{j=1}^nc_{i_j}v_{i_j})=\sum_{j=1}^nc_{i_j}T(v_{i_j}) \\ \amp \iff w\in \Span T(S)\text{.} \end{align*}
    This proves (2). The proof of (1) is similar, and (3) and (4) follow immediately from (1) and (2). Statement (5) is a result of the fact that \(T(U)=\im T\vert_U\) and \(U=\im T^{-1}\vert_{T(U)}\text{.}\) We leave (6) as an exercise for the reader.

    Corollary 1.21.11 Finite-dimensional spaces.

    Let \(V\) and \(W\) be finite dimensional vector spaces. The following statements are equivalent.
    1. \(V\) is isomorphic to \(W\text{.}\)
      🔗
      🔗
    2. \(\dim V=\dim W\text{.}\)

    Example 1.21.12 Matrix transformations.

    Prove that a matrix transformation \(T_A\colon F^n\rightarrow F^m\) is an isomorphism if and only if \(m=n\) and \(A\in \ML_{n,n}\) is invertible.
    🔗
    Solution.
    We know from Example 1.19.14 that matrix transformations are linear.
    🔗
    Assume \(m=n\) and \(A\in \ML_{n,n}\) is invertible. We claim that \(T_{A^{-1}}=T_A^{-1}\text{.}\) Indeed, for all \(\boldx\in F^n\text{,}\) we have
    \begin{align*} T_AT_{A^{-1}}\boldx \amp =T_A(A^{-1}\boldx)\\ \amp =AA^{-1}\boldx=\boldx\\ T_{A^{-1}}T_{A}\boldx \amp =T_{A^{-1}}(A\boldx)\\ \amp =A^{-1}A\boldx=\boldx\text{.} \end{align*}
    This proves that \(T_AT_{A^{-1}}=T_{A^{-1}}T_A=I_V\) and thus that \(T_{A^{-1}}=T_A^{-1}\text{,}\) as claimed. We conclude \(T_A\) is an isomorphism.
    🔗
    Lastly assume \(T_A\) is an isomorphism. By Corollary 1.21.11, we conclude that \(\dim F^n=\dim F^m\text{,}\) and hence that \(n=m\text{.}\) Since \(T_A\) is an isomorphism, it has a linear inverse \(S\colon F^n\rightarrow F^n\text{;}\) since all linear transformations of \(F^n\) are matrix transformations, we have \(S=T_B\) for some matrix \(B\in \ML_{n,n}\text{.}\) We have
    \begin{align*} T_AT_B=I_{F^n} \amp \implies AB\boldx=\boldx \text{ for all } \boldx\in F^n\implies AB=I\\ T_BT_A=I_{F^n} \amp \implies BA\boldx=\boldx \text{ for all } \boldx\in F^n\implies BA=I\text{.} \end{align*}
    Thus \(B=A^{-1}\text{,}\) showing that \(A\) is invertible.

    Section 1.6 Span and linear independence

    An \(F\)-vector space \(V\) is typically a very large set. Indeed, if the field \(F\) is infinite (e.g., \(\Q\text{,}\) \(\R\text{,}\) \(\C\)), and \(V\) is not the zero space, then \(V\) will also be infinite (as you can show with the help of Proposition 1.4.15). In developing our theory of vector spaces, one thing we will be concerned with is whether a smallish subset \(S\subseteq V\) can be used to generate the larger vector space \(V\text{,}\) where by generate we mean that every element of \(V\) can be written as a linear combination of elements of \(S\text{.}\) Using the terminology introduced below, we call \(S\) a spanning set of \(V\) in this case, and write \(V=\Span S\text{.}\)
    🔗
    Take the real vector space \(\R^3\text{,}\) for example. We saw in the last section that the set \(S=\{\bolde_1, \bolde_2, \bolde_3\}\) generates \(\R^3\) in precisely this sense. The utility of this state of affairs, is that any linear algebraic question about the (uncountably) infinite vector space \(\R^3\) can usually be reduced to a simple algebraic question about our finite set \(S=\{\bolde_1,\bolde_2,\bolde_3\}\text{.}\)
    🔗
    So where does linear independence fit in this picture. As you will quickly see, in general a nonzero vector space will have many different spanning sets. For example, the sets
    \begin{align*} S_1 \amp =\{\bolde_1,\bolde_2,\bolde_3\} \amp S_2\amp =S_1\cup \{(1,1,1)\} \amp S_3=\R^3 \end{align*}
    are all examples of spanning sets of \(\R^3\text{.}\) But with the aim of finding as small a spanning set as possible, we see that \(S_1\) is preferable to \(S_2\) and \(S_3\text{.}\) Put another way, the spanning sets \(S_2\) and \(S_3\) have what you might call redundancies: e.g., do we really need to include \((1,1,1)\) when it is already a linear combination of the \(\bolde_i\text{?}\) This gives way to a host of important questions we could ask. Can we do better than \(S_1\text{?}\) Is there a spanning set of \(\R^3\) with fewer than three elements? It turns out that the concept of linear independence defined below is exactly what we need to answer these redundancy-type questions.
    🔗

    Subsection 1.6.1 Span

    As defined below, span of a set of vectors is just the set of all linear combinations of those vectors.
    🔗

    Definition 1.6.1. Span.

    Let \(S\) be a subset of the \(F\)-vector space \(V\text{.}\) The span of \(S\text{,}\) denoted \(\Span S\text{,}\) is defined as follows.
    • If \(S=\emptyset\text{,}\) then we define
      \begin{equation*} \Span S=\Span\emptyset=\{\boldzero\}\text{.} \end{equation*}
      🔗
      🔗
    • If \(S\ne \emptyset\text{,}\) then we define \(\Span S\) as the set of all linear combinations of the vectors in \(S\text{:}\) i.e.,
      \begin{equation*} \Span S=\{v\in V\colon v=\sum_{k=1}^nc_{k}v_{k} \text{ for some } n\in \Z_+, v_k\in S, c_{k}\in F\} \text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Remark 1.6.2.

    Let \(S\) be tuple of vectors in \(V\text{.}\)
    1. The zero vector is always an element of \(\Span S\text{.}\) We treat the cases where \(S\) is empty or nonempty separately.
      🔗
      If \(S=\emptyset\text{,}\) then \(\Span S=\{\boldzero\}\) by definition.
      🔗
      If \(S\ne \emptyset\text{,}\) then it contains some element \(v\in S\text{,}\) in which case by definition \(S\) contains all its scalar multiples \(cv\text{,}\) \(c\in F\text{.}\) By Proposition 1.4.15, we have \(\boldzero=0v\text{,}\) showing that \(\boldzero\in \Span S\text{.}\)
      🔗
      🔗
    2. The set \(S\) is contained in \(\Span S\text{.}\) Indeed, given any \(v\in S\text{,}\) we have \(v=1v\in \Span S\text{.}\)
      🔗
      🔗
    3. For any singleton \(S=\{v\}\text{,}\) we have \(\Span(v)=\{cv\colon c\in F\}\text{,}\) the set of all scalar multiples of \(v\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 1.6.3. Examples in \(\R^2\).

    Let \(V=\R^2\text{.}\) For subset \(S\subseteq V\text{,}\) identify \(\Span S\) as a familiar geometric object. Use the visualization methods discussed in Subsection 1.5.2.
    1. \(\displaystyle S=\emptyset\)
      🔗
      🔗
    2. \(\displaystyle S=\{\boldzero\}\)
      🔗
      🔗
    3. \(S=\{(a,b)\}\text{,}\) \((a,b)\ne (0,0)\)
      🔗
      🔗
    4. \(\displaystyle S=\{(1,0),(0,1)\}\)
      🔗
      🔗
    5. \(\displaystyle S=\{(1,1),(2,2)\}\)
      🔗
      🔗
    6. \(\displaystyle S=\{(1,1),(1,2)\}\)
      🔗
      🔗
    7. \(\displaystyle S=\R^2\)
      🔗
      🔗
    🔗
    Solution.
    1. \(\Span \emptyset=\{(0,0)\}\text{,}\) the set containing just the origin, by definition.
      🔗
      🔗
    2. \(\Span\{\boldzero\}\) is the set of all scalar multiples of \(\boldzero\text{.}\) Thus \(\Span\{\boldzero\}=\{\boldzero\}\text{,}\) the set containing just the origin.
      🔗
      🔗
    3. \(\Span\{(a,b)\}\) is the set of all scalar multiples of the nonzero vector \((a,b)\text{.}\) Geometrically, this is the line that passes through the the origin and the point \((a,b)\text{.}\)
      🔗
      🔗
    4. By definition
      \begin{align*} \Span\{(1,0),(0,1)\}\amp =\{a(1,0)+b(0,1)\colon a,b\in \R\} \\ \amp =\{(a,b)\colon a,b\in\R\}\amp\\ \amp = \R^2\text{.} \end{align*}
      🔗
      🔗
    5. By definition
      \begin{align*} \Span\{(1,1),(2,2)\}\amp =\{a(1,1)+b(2,2)\colon a,b\in \R\}\\ \amp =\{(a+2b,a+2b)\colon a,b\in\R\} \amp \text{.} \end{align*}
      It is easy to see that this set is equal to
      \begin{equation*} \ell=\{(c,c)\colon t\in \R\}=\{(x,y)\in \R^2\mid x=y\}\text{,} \end{equation*}
      the line with equation \(y=x\text{.}\) Indeed, we have \(\Span S\subseteq \ell\text{,}\) since using our description above any element of \(\Span S\) is of the form \((a+2b,a+2b)\text{,}\) which satisfies \(x=y\text{,}\) and thus lies in \(\ell\text{.}\) Going the other way, given any \((c,c)\in \ell\text{,}\) we have \((c,c)=(a+2b, a+2b)\text{,}\) where \(a=1\) and \(b=0\text{,}\) showing \((c,c)\in \Span S\) and thus \(\ell\subseteq \Span S\text{.}\) Since \(\Span S\subseteq \ell\) and \(\ell\subseteq \Span S\text{,}\) we conclude that \(\Span S=\ell\text{.}\)
      🔗
      Note that in this case we have
      \begin{equation*} \Span\{(1,1), (2,2)\}=\Span \{(1,1)\}\text{,} \end{equation*}
      and thus that the vector \((2,2)\) is in some sense redundant with respect to the span operation.
      🔗
      🔗
    6. By definition
      \begin{align*} \Span S\amp =\{a(1,1)+b(1,2)\colon a,b\in \R\}\\ \amp =\{(a+b,a+2b)\colon a,b\in\R\} \amp \text{.} \end{align*}
      Claim: \(\Span S=\R^2\text{.}\) Since clearly, \(\Span S\subseteq \R^2\text{,}\) it remains only to show that \(\R^2\subseteq \Span S\text{:}\) i.e., we must show that given any \((c,d)\in \R^2\) there exist \(a,b\in \R\) such that \((a+b, a+2b)=(c,d)\text{,}\) or
      \begin{equation*} \begin{array}{ccccc} a \amp +\amp b \amp =\amp c\\ a \amp +\amp 2b \amp =\amp d \end{array}\text{.} \end{equation*}
      Interesting. To answer the question we need to show that for all \((c,d)\in \R^2\text{,}\) the linear system
      \begin{equation*} \begin{linsys}{2} x + y = c\\ x + 2y = d \end{linsys} \end{equation*}
      has a solution \((x,y)=(a,b)\text{.}\) In the next section we will develop a systematic approach for answering such questions. For now we can proceed in an ad hoc manner: namely, the first equation implies \(x=c-y\text{;}\) substituting this for \(x\) in the second equation yields the equality \(y=d-c\text{.}\) We conclude that \((x,y)=(2c-d,-c+d)\) is a solution. Tracing back through our logic we conclude that
      \begin{align} (c,d) \amp = (2c-d)(1,1)+(-c+d)(1,2)\text{,}\tag{1.6.1} \end{align}
      and thus that \((c,d)\in \Span S\) for all \((c,d)\in \R^2\text{,}\) as desired.
      🔗
      🔗
    7. From our remark above, we have \(\R^2=S\subseteq \Span S\text{.}\) Since \(\Span S\subseteq \R^2\) by definition, we conclude that \(\Span S=\R^2\text{.}\)
      🔗
      🔗
    🔗
    🔗
    🔗

    Definition 1.6.4. Spanning set.

    A subset \(S\) of an \(F\)-vector space \(V\) is called a spanning set (or is said to span \(S\)) if \(\Span S=V\text{.}\)
    🔗
    🔗
    When getting to know a vector space, one of the first things we will do is identify a convenient spanning set. Below we identify some standard spanning sets for some of the vector spaces we have introduced.
    🔗

    Example 1.6.5. Standard spanning sets.

    For most of the vector spaces we’ve introduced there is a natural spanning set that comes to mind. We will refer to these loosely as standard spanning sets.
    • Zero space.
      Let \(V=\{\boldzero\}\text{.}\) By definition the empty set \(S=\emptyset\) is a spanning set of \(V\text{.}\) We call this the standard spanning set of the zero space.
      🔗
      🔗
    • \(n\)-tuples.
      Let \(V=F^n\text{.}\) We claim \(S=\{\bolde_1,\bolde_2,\dots, \bolde_n\}\) is a spanning set for \(V\text{,}\) which we call its standard spanning set. Indeed, given any \((a_1,a_2,\dots, a_n)\in F^n\) it is easy to see that
      \begin{equation*} (a_1,a_2,\dots, a_n)=\sum_{i=1}^na_i\bolde_i\text{.} \end{equation*}
      🔗
      🔗
    • Function space, finite domain.
      Recall that by definition \(F^n\) is simply notation for the function space \(\mathcal{F}(I,F)\text{,}\) where \(I=\{1,2,\dots, n\}\text{.}\) Thinking of the elements \(\bolde_i\) as functions \(f_i\colon I\rightarrow F\text{,}\) we see they are defined as \(f_i(j)=1\) if \(j=i\) and \(f_i(j)=0\text{,}\) otherwise. Such functions are called indicator functions (or characteristic functions) on the set \(I\text{.}\) As such we can generalize our result about \(F^n\) as follows.
      🔗
      Let \(V=\mathcal{F}(I,F)\text{,}\) where \(I\) is a finite nonempty set. For each \(i\in I\) define the function \(\chi_i\colon I\rightarrow F\) as follows:
      \begin{align*} \chi_i(j)=\begin{cases} 1\amp \text{if } j=i\\ 0\amp\text{if } j\ne i\end{cases} \amp \text{.} \end{align*}
      We claim that the set \(S=\{\chi_i\mid i\in I\}\) is a spanning set for \(\mathcal{F}(I,F)\text{.}\) Indeed given any function \(f\colon I\rightarrow F\text{,}\) consider the function
      \begin{equation*} g=\sum_{i\in I}f(i)\chi_i\in \Span S\text{.} \end{equation*}
      For all \(j\in I\text{,}\) we have
      \begin{align*} g(j) \amp =\sum_{i\in I}f(i)\chi_i(j)\\ \amp = f(j)\chi_j(j) \amp (\chi_i(j)=0 \text{ for } i\ne j)\\ \amp = f(j)\cdot 1 \amp (\chi_j(j)=1)\\ \amp = f(j)\text{.} \end{align*}
      We conclude that \(f=g\) and thus that \(f\in \Span S\text{.}\)
      🔗
      🔗
    🔗
    🔗
    A crucial detail in the last example was that \(I\) was a finite set. Indeed, since by definition a linear combination is a finite sum of scalar multiples of vectors, the expression \(g=\sum_{i\in I}c_i \chi_i\) only makes sense if \(I\) is finite. Since there is no finiteness condition on \(S\) in the definition of \(\Span S\text{,}\) however, we can still ask whether \(S=\{\chi_i\mid i\in I\}\) is a spanning set of \(\mathcal{F}(I,F)\) in general. As the next example shows, the answer is no!
    🔗

    Example 1.6.6. Function space, infinite domain.

    Let \(F\) be a field, let \(V=\mathcal{F}(\N, F)\text{,}\) the set of functions from \(\N=\{0,1,\dots\}\) to \(F\text{,}\) and for all \(i\in \N\text{,}\) let \(\chi_i\colon \N\rightarrow F\) be the indicator function defined as \(\chi_i(n)=1\) if \(n=1\) and \(\chi_i(n)=0\) if \(n\ne i\text{.}\) Show that \(S=\{\chi_i\mid i\in \N\}\) does not span \(V\) by producing an explicit function \(f\colon \N\rightarrow F\) that cannot be written as a linear combination of the \(\chi_i\text{.}\)
    🔗
    Solution.
    Consider the function \(f\colon \N\rightarrow F\) defined by \(f(n)=1\) for all \(n\in \N\text{.}\) We claim that \(f\notin \Span S\text{.}\) In fact, we will show that any \(g\in \Span S\) satisfies \(g(n)=0\) for all but finitely many \(n\in \N\text{.}\) It then follows that \(f\notin\Span S\) since \(f\) is nonzero for all \(n\in N\text{.}\)
    🔗
    To prove the claim, note that by definition, any \(g\in \Span S\text{,}\) is of the form
    \begin{equation*} g=\sum_{j=1}^k c_{i_j}\chi_{i_j}\text{.} \end{equation*}
    But then for all \(n\) in the infinite set
    \begin{equation*} \N-\{i_1,i_2,\dots, i_k\}\text{,} \end{equation*}
    we have
    \begin{align*} g(n) \amp =\sum_{j=1}^kc_{i_j}\chi_{i_j}(n)\\ \amp =\sum_{j-1}^kc_{i_j}0 \amp (n\ne i_j\implies \chi_{i_j}(n)=0)\\ \amp = 0\text{,} \end{align*}
    showing that \(g(n)=0\) for all but finitely many \(n\in \N\text{.}\)
    🔗

    Subsection 1.6.2 Linear independence

    As mentioned above, the notion of linear independence is precisely what we need to guarantee that a given spanning set \(S\) has no “redundancies”. This is not immediately evident from Definition 1.6.8, but will be made clear in Theorem 1.6.10.
    🔗
    It turns out that, unlike the notion of span, linear independence is best understood as a property not of a set of vectors, but rather of a tuple of vectors. As such, we will first go full tuple here before getting to the actual definition.
    🔗

    Definition 1.6.7. Tuples.

    Let \(I\) and \(A\) be sets. An \(A\)-valued tuple indexed by \(I\) is a function \(f\colon I\rightarrow A\text{.}\) The set of all \(A\)-valued tuples indexed by \(I\) is denoted \(A^I\text{:}\) i.e.,
    \begin{equation*} A^I=\mathcal{F}(I,A)\text{.} \end{equation*}
    In this setting we will use an alternative tuple notation, writing
    \begin{equation*} f=(a_i)_{i\in I} \end{equation*}
    to denote the function \(f\colon I\rightarrow A\) defined as \(f(i)=a_i\) for all \(i\in I\text{.}\)
    🔗
    Given a tuple \(v=(a_i)_{i\in I}\text{,}\) we call \(a_i\) the \(i\)-th component (or coordinate, or entry, or term)
    🔗
    🔗
    having gotten the general notion of a tuple out of the way, we can now define linear independence as a property that either holds or does not hold for a given tuple of vectors \((v_i)_{i\in I}\) in a vector space.
    🔗

    Definition 1.6.8. Linear independence.

    Let \(V\) be an \(F\)-vector space. A tuple \(S=(v_i)_{i\in i}\) of vectors of \(V\) is linearly independent if there is no nontrivial linear combination of the \(v_i\) equal to \(\boldzero\text{:}\) i.e., if \(\sum_{j=1}^nc_{i_j}v_{i_j}=\boldzero\) for some set of indices \(\{i_1,i_2,\dots, i_n\}\subset I\) and scalars \(c_{i_j}\text{,}\) then \(c_i=0\) for all \(i\in I\text{.}\) Using logical shorthand:
    \begin{equation} \sum_{j=1}^nc_{i_j}v_{i_j}=\boldzero\implies c_{i_j}=0 \text{ for all } i_j\in \{i_1,i_2,\dots, i_n\}\text{.}\tag{1.6.2} \end{equation}
    We say \((v_i)_{i\in I}\) is linearly dependent if it is not linearly independent: i.e., if there is a nontrivial linear combination \(\sum_{j=1}^nc_{i_j}v_{i_j}=\boldzero\text{.}\)
    🔗
    Lastly, observe that in the case where \(I=\emptyset\text{,}\) an empty tuple \(S=()\) of vectors is linearly independent as it satisfies the implication (1.6.2) vacuously.
    🔗
    🔗

    Example 1.6.9. Linear independence.

    For each tuple \(t=(v_i)_{i\in I}\) of the given vector space \(V\text{,}\) decide whether \((v_i)_{i\in I}\) is linearly independent.
    1. \(V=F^n\text{,}\) \(t=(\bolde_i)_{i=1}^n\)
      🔗
      🔗
    2. \(V=\mathcal{F}(I, F)\text{,}\) \(t=(\chi_i)_{i\in I}\text{,}\) where as usual, \(\chi_i\) is the \(i\)-th indicator function.
      🔗
      🔗
    3. \(V=\R^3\text{,}\) \(t=(v_1,v_2,v_3)\text{,}\) where
      \begin{align*} v_1 \amp = (1,0,2) \amp v_2\amp =(-1,0,2) \amp v_3=(1,0,6) \text{.} \end{align*}
      🔗
      🔗
    🔗
    Solution.
    🔗
    🔗
    🔗

    Theorem 1.6.10. Span and independence.

    Let \(S=(v_i)_{i\in I}\) be a nonempty tuple of vectors of the vector space \(V\text{.}\) The following statements are equivalent.
    1. \(S\) is linearly dependent.
      🔗
      🔗
    2. There is an index \(i_{0}\in I\) such that \(v_{i_{0}}\) can be written as a linear combination of the other \(v_i\)’s: i.e., there exists \(i_k\in I\) and and a finite set of indices \(J\) not containing \(i_0\text{,}\) such that
      \begin{equation*} v_{i_0}=\sum_{j\in J}c_jv_j \end{equation*}
      for some \(c_j\in F\text{.}\)
      🔗
      Additionally, when this is the case we have
      \begin{equation} \Span\{v_i\mid i\in I\}=\Span\{v_i\mid i\in I-\{i_k\}\}\text{.}\tag{1.6.3} \end{equation}
      🔗
      🔗
    🔗
    🔗

    Proof.

    If the tuple \(S=(v_i)_{i\in I}\) is linearly dependent, then there is a nontrivial linear combination
    \begin{equation*} c_{i_1}v_1+c_{i_2}v_2+\cdots +c_{i_n}v_{i_n}=\boldzero\text{,} \end{equation*}
    where \(i_j\in I\text{.}\) Since the linear combination is nontrivial, we have \(c_{i_k}\ne 0\) for some \(1\leq k\leq n\text{.}\) After a little vector arithmetic, we can then solve for \(v_{i_k}\text{:}\)
    \begin{equation*} v_{i_k}=\sum_{j\ne k}\frac{c_{i_j}}{c_{i_k}}v_{i_j}\text{.} \end{equation*}
    This shows \(v_{i_k}\) is a linear combination of the vectors \(v_i\text{,}\) where \(i\ne i_k\text{,}\) and thus that \(v_{i_k}\in \Span(v_i)_{i\in I-\{i_k\}}\text{.}\)
    🔗
    Conversely, if we have \(v_{i_k}\in \Span(v_i)_{i\in I-\{i_k\}}\text{,}\) then we have
    \begin{equation} v_{i_k}=\sum_{j=1}^nd_{i_j}v_{i_j}\tag{1.6.4} \end{equation}
    for some \(i_j\in I\) and \(d_{i_j}\in F\text{,}\) whence it follows that
    \begin{equation*} -d_{i_1}v_{i_1}-d_{i_2}v_{i_2}-\cdots --d_{i_n}v_{i_n}+v_{i_k}=\boldzero \end{equation*}
    is a nontrivial linear combination of the \(v_i\) equal to \(\boldzero\text{.}\) We conclude that \(S=(v_i)_{i\in i}\) is linearly dependent.
    🔗
    We have thus proved that \(S\) is linearly dependent if and only if some \(v_{i_k}\) can be written as a linear combination of the other vectors \(v_i\text{.}\) We now prove that when this is the case, we have
    \begin{equation*} \Span\{v_i\mid i\in I-\{i_k\}\}=\Span\{v_i\mid i\in I\}\text{.} \end{equation*}
    It is clear that
    \begin{equation*} \Span\{v_i\mid i\in I-\{i_k\}\}\subseteq \Span\{v_i\mid i\in I\}\text{.} \end{equation*}
    Indeed, more generally, if \(S\subseteq S'\subseteq V\text{,}\) then clearly \(\Span S\subseteq \Span S'\text{,}\) since any linear combination of the smaller set \(S\) is also a linear combination of the larger set \(S'\text{.}\)
    🔗
    For the other direction, take \(v\in \Span\{v_i\mid i\in I\}\text{.}\) By definition, we can write \(v\) as a finite linear combination of the vectors \(v_i\text{.}\) It follows that can write
    \begin{equation*} v=c_{i_k}v_{i_k}+\sum_{i\in J}c_iv_i\text{,} \end{equation*}
    where \(J\) is a finite subset of \(I\) not containing \(i_k\text{.}\) (Note that \(c_{i_k}\) is allowed to be 0 here.) Since \(v_{i_k}\) is assumed to be a linear combination of the other vectors \(v_i\text{,}\) we can express \(v_{i_k}\) as in (1.6.4), in which case we have
    \begin{equation*} v=\sum_{j=1}^nc_{i_k}d_{i_j}v_{i_j}+\sum_{i\in J}c_iv_i\text{.} \end{equation*}
    Since \(i_j\ne i_k\) for all \(1\leq j\leq n\text{,}\) and since \(i_k\notin J\text{,}\) we see that this is a linear combination of the tuple \((v_i)_{i\in I-\{i_k\}}\text{.}\) Thus \(v\in \Span(v_i)_{i\in I-\{i_k\}}\text{,}\) showing that
    \begin{equation*} \Span\{v_i\mid i\in I\}\subseteq \Span\{v_i\mid i\in I-\{i_k\}\}\text{,} \end{equation*}
    as desired.

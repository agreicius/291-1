    Section 1.1 Natural numbers: Peano axioms

    Theorem 1.1.1. Peano Axioms.

    There is a set \(\N\) satisfying the following properties.
    1. There is a function \(S\colon \N\rightarrow \N\) defined on \(\N\) called the successor function.
      🔗
      🔗
    2. There is an element \(0\in \N\) such that \(0\ne S(n)\) for all \(n\in \N\text{.}\)
      🔗
      🔗
    3. The successor function is injective: i.e., for all \(m,n\in \N\text{,}\) if \(S(m)=S(n)\text{,}\) then \(m=n\text{.}\) Using logical shorthand, this means
      \begin{equation*} m\ne n \implies S(m)\ne S(n)\text{,} \end{equation*}
      or equivalently,
      \begin{equation*} S(m)=S(n) \implies m=n \end{equation*}
      for all \(m,n\in \N\text{.}\)
      🔗
      🔗
    4. Induction principle.
      If \(A\) is a subset of \(\N\) satisfying
      1. \(0\in A\text{,}\) and
        🔗
        🔗
      2. for all \(n\in \N\text{,}\) if \(n\in A\text{,}\) then \(S(n)\in A\text{,}\)
        🔗
        🔗
      then \(A=\N\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.

    🔗
    🔗
    Once we have a set \(\N\) satisfying the properties of Theorem 1.1.1, called the Peano axioms, we can recognize our old friend \(\{0,1,2,\dots, \}\) by introducing the notation \(S(n)=n+1\) for all \(n\in \N\text{,}\) and adding some additional names of elements resulting from successive application of \(S\) starting with \(0\text{:}\) e.g.,
    \begin{align*} 1 \amp =S(0)=0+1 \amp 2\amp =S(1)=1+1 \amp 3\amp=S(2)=2+1\\ 4 \amp = S(3)=3+1 \amp 5\amp=S(4)=4+1 \amp 6\amp=S(5)=5+1\\ 7 \amp = S(6)=6+1 \amp 8\amp=S(7)=7+1 \amp 9\amp=S(8)=8+1\text{.} \end{align*}
    Next with the help of the induction principle, we can define not just a successor function, but further a full-blown addition operation
    \begin{align*} +\colon \N\times\N \amp \rightarrow \N\\ (m,n) \amp\mapsto m+n\text{.} \end{align*}
    We will not do this in detail, as it a tad technical (involving a further recursive principle), but roughly speaking \(m+n\) is defined as applying the successor function \(n\) times to \(m\text{:}\) i.e.,
    \begin{equation*} m+n=\underset{n \text{ times}}{\underbrace{S(S(\dots S(m)))}}\text{.} \end{equation*}
    At this point we are well on our way to reconstructing the usual arithmetic on \(\N\text{;}\) we can give a similar type of definition for the multiplication operation
    \begin{equation*} (m,n)\mapsto m\cdot n\text{.} \end{equation*}

    🔗

    Corollary 1.1.2.

    Let \(a\in \Z\text{,}\) and let \(A\) be a subset of \(\Z_{\geq a}\text{.}\) If \(A\) satisfies
    1. \(a\in A\text{,}\) and
      🔗
      🔗
    2. for all \(n\geq a\text{,}\) if \(n\in A\text{,}\) then \(n+1\in A\text{,}\)
      🔗
      🔗
    then \(A=\Z_{\geq a}\text{.}\)
    🔗
    🔗
    The fourth property of Theorem 1.1.1 directly gives rise to a proof technique for showing that a given subset \(A\) of \(\N\) is actually all of \(\N\text{:}\) namely, show that (i) \(0\in \N\text{,}\) and (ii) show that for all \(n\in \N\text{,}\) if \(n\in A\text{,}\) then \(n+1\in A\text{.}\) As stated, this is a proof technique for showing an equality of sets (\(A=\N\)). It is useful, however to give an equivalent formulation of this principle that yields a technique for proving a technique for proving universal quantifications of the form
    \begin{equation*} \text{For all integers } n\geq b, \, P(n)\text{,} \end{equation*}
    where \(b\) is a fixed starting integer, called the base, and \(P\) is a predicate defined on the integers. Using logical shorthand, we seek a proof technique for showing that propositions of the form
    \begin{equation*} \forall n\in \Z_{\geq b}\ P(n)\text{.} \end{equation*}
    The technique in question is called proof by induction.
    🔗

    Procedure 1.1.3. Proof by induction.

    Let \(b\) be an integer, and let \(P(x)\) be a predicate defined on all integers \(n\geq b\text{.}\) To prove the proposition
    \begin{equation*} \forall n\in \Z_{\geq b}\ P(n)\text{,} \end{equation*}
    proceed as follows.
    • Base step.
      Prove that \(P(b)\) is true.
      🔗
      🔗
    • Induction step.
      Prove that for all integers \(n\geq b\text{,}\) if \(P(n)\) is true, then \(P(n+1)\) is true. Using logical: prove the proposition
      \begin{equation} \forall n\geq b \ P(n)\implies P(n+1)\text{.}\tag{1.1.1} \end{equation}
      🔗
      🔗
    🔗
    🔗

    Example 1.1.4. Induction: sum of first \(n\) integers.

    Prove the identity
    \begin{equation*} \sum_{k=1}^n k=\frac{n(n+1)}{2} \end{equation*}
    for all \(n\geq 1\text{.}\) Recall:
    \begin{equation*} \sum_{k=1}^n k=1+2+\cdots +n\text{.} \end{equation*}
    🔗
    Solution.
    We prove the proposition by induction.
    🔗

    Step 0: preparation.

    The proposition is modeled logically as \(\forall n\geq 1 \, P(n)\text{,}\) where \(P(n)\) is the proposition that
    \begin{equation*} \sum_{k=1}^n k=\frac{n(n+1)}{2}\text{.} \end{equation*}
    🔗
    🔗

    Base step: \(n=1\).

    The proposition \(P(1)\) is the statement that
    \begin{equation*} 1=\frac{1(1+1)}{2}\text{,} \end{equation*}
    which is true since
    \begin{equation*} \frac{1(1+1)}{2}=\frac{2}{2}=1\text{.} \end{equation*}
    🔗
    🔗

    Induction step.

    We must show the universal implication
    \begin{equation*} \forall n\in \Z_{\geq 1}\ P(n)\implies P(n+1)\text{.} \end{equation*}
    Let \(n\geq 1\text{,}\) and assume \(P(n)\) is true: i.e.,
    \begin{equation*} \sum_{k=1}^n k=\frac{n(n+1)}{2} \end{equation*}
    The proposition \(P(n+1)\) states that
    \begin{equation*} \sum_{k=1}^{n+1} k=\frac{(n+1)(n+2)}{2}\text{.} \end{equation*}
    We prove this, assuming \(P(n)\text{,}\) via a chain of equalities:
    \begin{align*} \sum_{k=1}^{n+1} k\amp= \sum_{k=1}^{n} k+(n+1) \\ \amp=\frac{n(n+1)}{2}+n+1\amp (\text{induction hyp.}) \\ \amp =\frac{n(n+1)+2(n+1)}{2}\\ \amp =\frac{(n+1)(n+2)}{2}\text{,} \end{align*}
    as desired.
    🔗
    🔗
    Having completed our base and induction steps, our proof is now finished.
    🔗
    🔗
    🔗

    Procedure 1.1.5. Proof by strong induction.

    Let \(b\) be an integer, and let \(P(x)\) be a predicate defined on all integers \(n\geq b\text{.}\) To prove the proposition
    \begin{equation*} \forall n\in \Z_{\geq b}\ P(n)\text{,} \end{equation*}
    proceed as follows.
    • Base step.
      Prove that \(P(b)\) is true.
      🔗
      🔗
    • Strong induction step.
      Prove that for all integers \(n\geq b\text{,}\) if \(P(x)\) is true for all integers \(b\leq x\leq n\text{,}\) then \(P(n+1)\) is true. Using logical: prove the proposition
      \begin{equation} \forall n\geq b\, \left(P(b)\land P(b+1)\cdots \land P(n)\right) \implies P(n+1)\text{.}\tag{1.1.2} \end{equation}
      🔗
      🔗

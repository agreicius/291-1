    Section 1.2 Reals, rationals, fields

    Subsection 1.2.1 Real numbers

    Having established the existence of the natural numbers \(\N\) and integers \(\Z\) with a reasonable degree of rigor, we now move on to build larger number systems. We will proceed somewhat nonlinearly, beginning with the real numbers \(\R\) and then defining the rational numbers \(\Q\) as a subset of \(\R\text{.}\) In so doing, we are acting in blatant disregard of the fact that the standard constructions build the reals \(\R\) out of the rationals \(\Q\text{.}\) Those constructions are landmark results in the history of mathematics, and it might come as a surprise that mathematicians didn’t hit upon a rigorous construction of \(\R\) until the 19th century. The tools and concepts involved in these constructions, however, are properly the domain of real analysis, and as such, we do not tackle that task until the first quarter of our Math 320 or Math 321 sequence. Instead, we state without proof an existence theorem of \(\R\) that articulates some (but not all) key properties of this number system, as well as its relation to \(\Z\text{.}\)
    🔗

    Theorem 1.2.1. Real numbers.

    There is a set \(\R\) satisfying the following properties.
    1. \(\R\) contains the integers \(\Z\) as a subset: i.e., \(\Z\subseteq \R\text{.}\)
      🔗
      🔗
    2. Field.
      The addition and multiplication operations of \(\Z\) extend to addition and multiplication operations on \(\R\) satisfying the field axioms of Definition 1.2.5.
      🔗
      🔗
    3. Ordered field.
      The the “less than” relation \(< \) of the integers extends to a relation \(< \) on \(\R\) satisfying the following properties.
      1. For all \(a,b,c\in \Z\text{,}\) if \(a< b\text{,}\) then \(a+c< b+c\text{.}\)
        🔗
        🔗
      2. For all \(a,b\in \R\) and \(c\in \R\) with \(c> 0\text{,}\) if \(a< b\text{,}\) then \(ac< bc\text{.}\)
        🔗
        🔗
      🔗
      🔗
    4. Archimedean property.
      For all real numbers \(r\in \R\text{,}\) there is a natural number \(n\in \N\) such that \(r< n\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Remark 1.2.2. Ordered archimedean field.

    The stated properties of Theorem 1.2.1 establishes \(\R\) as an ordered archimedean field. It turns out that these properties alone are not enough to uniquely characterize \(\R\text{.}\) Indeed, it is easy to see that the rationals \(\Q\) also satisfy these properties. However, it turns out that we can pin down \(\R\) uniquely with one additional property: the least upper bound property. We state it here for your reference, but again, this topic is really the domain of a real analysis course.
    • Least upper bound property.
      Given any nonempty subset \(A\subseteq \R\text{,}\) if \(A\) has an upper bound in \(\R\) (i.e., there is a real number \(r\) such that \(a\leq r\) for all \(a\in A\)), then \(A\) has a least upper bound in \(\R\) (i.e., there is a real number \(s\in \R\) such that \(s\) is an upper bound for \(A\text{,}\) and if \(t\in \R\) is any other upper bound for \(A\text{,}\) then \(s\leq t\)).
      🔗
      🔗
    It is the existence of least upper bounds, as defined above, that make \(\R\) a much richer number system containing \(\Z\) then say \(\Q\text{.}\) For example, taking the set
    \begin{equation*} A=\{q\in \Q\mid q^2\leq 2\}\text{,} \end{equation*}
    it is easy to see that \(A\) has an upper bound (e.g., \(2\)), and thus that there is a real number \(s\in \R\) that is a least upper bound. You can then show that we must have \(s^2=2\text{,}\) and hence that \(s\) is a square root of \(2\text{.}\)
    🔗
    🔗
    The following corollary of the archimedean property follows from the induction principle of \(\N\) (or equivalently, the well-ordered property).
    🔗

    Corollary 1.2.3. Archimedean principle.

    For any real number \(r\in \R\text{,}\) there is a unique integer \(n\in \Z\) such that
    \begin{align} n \amp \leq r < n+1\text{.}\tag{1.2.1} \end{align}
    🔗
    🔗

    Proof.

    This is left as a homework exercise.
    🔗
    🔗

    Definition 1.2.4. Floor function.

    Given \(r\in \R\text{,}\) we denote by \(\floor{r}\) the unique integer \(n\in \Z\) satisfying \(n\leq r< n+1\text{.}\) The function
    \begin{align*} \floor{\phantom{x}}\colon \R \amp \rightarrow \R\\ r \amp \mapsto \floor{r} \end{align*}
    is called the floor function.
    🔗
    🔗
    🔗

    Subsection 1.2.2 Fields

    Definition 1.2.5. Field.

    A field is a set \(F\) together with two operations
    \begin{align*} +\colon F\times F \amp\rightarrow F \amp \times\colon F\times F\amp \rightarrow F \\ (a,b)\amp\mapsto a+b \amp (a,b)\amp \mapsto a\,b \end{align*}
    called addition and multiplication respectively, satisfying the following axioms.
    1. Commutativity.
      For all \(a,b\in F\) we have
      \begin{align*} a+b \amp = b+a \amp ab=ba\text{.} \end{align*}
      🔗
      🔗
    2. Associativity.
      For all \(a,b,c \in F\) we have
      \begin{align*} a+(b+c)\amp =(a+b)+c \amp a(bc)=(ab)c\text{.} \end{align*}
      🔗
      🔗
    3. Distributivity.
      For all \(a,b,c \in F\) we have
      \begin{equation*} a(b+c)=ab+ac\text{.} \end{equation*}
      🔗
      🔗
    4. Additive identity.
      There is an element \(0\in F\) satisfying
      \begin{equation*} 0+a=a \end{equation*}
      for all \(a\in F\text{.}\) The element \(0\) is called the additive identity.
      🔗
      🔗
    5. Additive inverse.
      For all \(a\in F\) there is an element \(-a\in F\) satisfying
      \begin{equation*} a+ -a=0\text{.} \end{equation*}
      The element \(-a\) is called the additive inverse of \(a\text{.}\)
      🔗
      🔗
    6. Multiplicative identity.
      There is an element \(1\in F\) satisfying
      \begin{equation*} 1\times a=a \end{equation*}
      for all \(a\in F\text{.}\) The element \(1\) is called the multiplicative identity.
      🔗
      🔗
    7. Multiplicative inverse.
      For all nonzero elements \(a\in F\) (i.e., \(a\ne 0\)) there is an element \(a^{-1}\in F\) satisfying
      \begin{equation*} a\,a^{-1}=1\text{.} \end{equation*}
      The element \(a^{-1}\text{,}\) also denoted \(1/a\text{,}\) is called the multiplicative inverse of \(a\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Remark 1.2.6. Anatomy lesson: function and Cartesian product notation.

    The expressions
    \begin{align*} +\colon F\times F\colon \amp \rightarrow F \amp \times\colon F\times F\colon \amp\rightarrow F \end{align*}
    used in Definition 1.2.5 use a combination of function notation (see Definition 0.2.1) and Cartesian product notation (see Definition 0.1.19). Let’s break it down.
    🔗
    Firstly, in general, given sets \(A\) and \(B\text{,}\) the set \(A\times B\text{,}\) called the Cartesian product of \(A\) and \(B\text{,}\) is defined as the set of all pairs \((a,b)\text{,}\) where \(a\in A\) and \(b\in B\text{:}\) i.e.,
    \begin{equation*} A\times B=\{(a,b)\mid a\in A, b\in B\}.\text{.} \end{equation*}
    Next, the notation \(f\colon C\rightarrow D\) denotes a function named \(f\) whose domain is the set \(C\) and whose codomain is the set \(D\text{.}\) When we want to give more information about how the function is evaluated on inputs, we include a separate line below using the “mapsto” symbol \(\mapsto\text{:}\)
    \begin{align*} f\colon C \amp \rightarrow D\\ c \amp \mapsto f(c)\text{.} \end{align*}
    Putting the two notations together, the expression
    \begin{align*} A\times B\amp \rightarrow C\amp \\ (a,b) \amp \mapsto c \end{align*}
    denotes a function that takes as input a pair of elements \((a,b)\text{,}\) where \(a\in A\) and \(b\in B\text{,}\) and returns as output an element \(c\in C\text{.}\)
    🔗
    🔗

    Remark 1.2.7. Arithmetic and existential axioms.

    We will call Axioms (i)-(iii) the arithmetic axioms, as they stipulate that our operations satisfy some familiar properties from arithmetic. Additionally, we will call Axioms (iv)-(vii) the existential axioms as they posit the existence of certain special elements inside the underlying set \(F\) of the field: namely, special elements denoted \(0\) and \(1\) satisfying Axioms (iv) and (vi), for each element \(a\in F\) a special associated element \(-a\) satisfying Axiom (v), and for each nonzero element \(a\ne 0\) a special associated element \(a^{-1}\) satisfying Axiom (vii).
    🔗
    🔗

    Warning 1.2.8. Names and prejudices.

    We use familiar looking notation to describe the special elements of a field \(F\) (e.g., \(0,1,-a, 1/a\)), but keep in mind that these are just names for certain special elements satisfying various axioms in Definition 1.2.5.
    🔗
    When verifying whether a given set \(F\) with given operations \(+\) and \(\times\) is a field, we make no assumptions beforehand as to which elements of \(F\) serve as these special elements. It is up to us to identify these special elements and verify that they satisfy the relevant axioms. As such, it is important each time we are confronted with a new potential field, that we come with no prejudices as to which elements serve as additive/multiplicate identities/inverses; these roles depend on how the operations themselves are defined. Example 1.2.14 is a nice illustration of this approach.
    🔗
    🔗
    From the two field operations of addition and multiplication, along with the field axioms, we can define some simple additional operations like substraction, division, and integer exponentiation.
    🔗

    Definition 1.2.9. Subtraction, division, integer powers.

    Let \(F\) be a field.
    1. Subtraction.
      Given elements \(a, b\text{,}\) we define their difference \(a-b\) as
      \begin{equation*} a-b=a+\, -b\text{.} \end{equation*}
      🔗
      🔗
    2. Division.
      Given elements \(a,b\in F\) with \(b\ne 0\text{,}\) we define their quotient \(a/b\) as
      \begin{equation*} a/b=a\, b^{-1}\text{.} \end{equation*}
      🔗
      🔗
    3. Integer powers.
      Given any \(a\in F\text{,}\) we define \(a^0=1\) and
      \begin{equation*} a^{n}=\underset{n \text{ times}}{\underbrace{a\cdot a \cdots a}} \end{equation*}
      where \(n\) is any positive integer.
      🔗
      Furthermore, if \(a\ne 0\) and \(n\geq 0\text{,}\) we define
      \begin{equation*} a^{-n}=(a^{-1})^n\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Example 1.2.10. Real numbers.

    Thanks to Theorem 1.2.1 the set \(\R\text{,}\)together with the operations of real number addition and real number multiplication, constitutes a field.
    🔗
    🔗
    As mentioned above, the rationals \(\Q\) are another field containing \(\Z\text{:}\) in fact, another ordered archimedean field. We define them now as a subset of \(\R\text{.}\)
    🔗

    Definition 1.2.11.

    The set \(\Q\) of rational numbers is the subset of \(\R\) defined as
    \begin{align} \Q \amp =\{q\in \R\mid q=m/n \text{ for some } m,n\in \Z\}\text{.}\tag{1.2.2} \end{align}
    🔗
    🔗

    Proposition 1.2.12. \(\Q\) is a field.

    Real number addition and multiplication restrict to well-defined operations
    \begin{align*} +\colon \Q\times \Q \amp \rightarrow \Q \amp \times\colon \Q\times \Q\amp\rightarrow \Q \end{align*}
    that give \(\Q\) the structure of a field.
    🔗
    🔗

    Proof.

    1. It is clear that we can add and multiply two rational numbers; what we need to show is that the result of applying either of these operations to two rational numbers is again a rational number. In other words, we must show that the sum of two rational numbers is a rational number, and the product of two rational numbers is a rational number. To this end, let \(r,s\in \Q\text{,}\) and write \(r=m/n\) and \(s=p/q\text{,}\) where \(m,n,p,q\in \Z\text{.}\) We then have
      \begin{align*} r+s \amp = \frac{mq+pn}{mn} \amp rs\amp=\frac{mp}{nq}\text{.} \end{align*}
      Since \(mq+pn,mn, mp, nq\in \Z\text{,}\) we see that \(r+s, rs\in \Q\text{,}\) as desired.
      🔗
      🔗
    2. Once we know that real number addition and multiplication restrict to well-defined operations on \(\Q\text{,}\) that these restricted operations satisfy the field axioms follows directly from the fact that the original operations on \(\R\) satisfy these axioms. For example, since addition and multiplication are satisfy Axiom (i) for all real numbers, they certainly satisfy Axiom (i) for all rational numbers.
      🔗
      Similarly, the existential Axioms (iv)-(vii) are easily seen to be satisfied for the operations restricted to \(\Q\) once we observe that \(0,1\in \Q\text{,}\) and that given any nonzero \(r=m/n\in \Q\text{,}\) we have \(r^{-1}=n/m\in \Q\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 1.2.13. Integers.

    Explain why \(\Z\) is not a field with respect to interger addition and multiplication. More specifically, which field axioms are satisfied, and which fail?
    🔗
    Solution.
    1. An argument very similar to the one in Proposition 1.2.12 shows that the sum and product of two integers is again an integer, and hence that restricting these operations to \(\Z\) yields a well-defined operation on \(\Z\text{.}\)
      🔗
      🔗
    2. The integers fail to be a field with respect to these operations as Axiom (vii) fails. To this end, by way of counterexample, we claim that the integer \(2\) does not have a multiplicative inverse in \(\Z\text{.}\) Indeed, if there were an integer \(n\) such that \(2n=1\text{,}\) then we’d have \(n\ne 0\) and
      \begin{equation*} \abs{2n}=2\abs{n}=\abs{1}=1\text{.} \end{equation*}
      But for all nonzero integers \(n\in \Z\text{,}\) we have \(\abs{n}\geq 1\text{,}\) and hence
      \begin{equation*} 2\abs{n}\geq 2\cdot 1=1> 1\text{,} \end{equation*}
      a contradiction. We conclude that there is no integer \(n\) satisfying \(2n=1\text{,}\) and hence that \(2\) has no multiplicative inverse in \(\Z\text{.}\) Thus \(\Z\) is not a field with respect to these operations.
      🔗
      As it turns out, Axiom (vii) is the only field axiom that \(\Z\) fails, making it still a pretty darn good number system to work with. In fact, we have a name for number systems that satisfy at least Axioms (i)-(vi) of the field axioms: they are called rings.
      🔗
      🔗
    🔗
    🔗
    🔗

    Example 1.2.14. Field of two elements.

    Let \(F=\{a,b\}\) be a set containing two distinct elements. Define addition and multiplication on \(F\) as follows:
    \begin{align*} a+a \amp = a \amp a+b\amp = b \amp b+a \amp = b \amp b+b\amp = a\\ aa \amp = a \amp ab\amp= a \amp ba\amp = a \amp bb=b\text{.} \end{align*}
    Verify that \(F\text{,}\) together with these two operations, constitutes a field. Make explicit which elements of \(F\) serve as the additive/multiplicative identities/inverses.
    🔗
    Solution.
    Since \(F\) only has two elements, showing that Axioms (i)-(iii) hold is a simple matter of looking at all the possible cases: in other words, we can resort to a proof by exhaustion for these axioms. For example, verifying commutativity of multiplication requires looking at just 4 different cases. Furthermore, since it is trivially true that \(a a=aa\) and \(bb=bb\text{,}\) we need only look at the “mixed products” \(ab\) and \(ba\text{;}\) and in this case we see by the definition that
    \begin{equation*} ab=a=ba\text{.} \end{equation*}
    Similar arguments can be mounted for the rest of these arithmetic axioms.
    🔗
    We now turn to the existential axioms. First, we claim that \(a\) serves as the additive identity in this case: i.e., we have \(0=a\) for this field. To verify this, we need to show that \(a\) satisfies the defining axiom of the additive identity: namely, that \(a+a=a\) for any \(a\in F\text{.}\) But this follows directly from the very definition of addition on \(F\text{,}\) as we declared that \(a+a=a\) and\(a+b=b\text{.}\) A similar argument shows that the element \(b\) acts as the multiplicative identity in this field: i.e., we have \(1=b\text{.}\)
    🔗
    Lastly we must show that each element of \(F\) has an additive inverse satisfying Axiom (v), and that each nonzero element of \(F\) has a multiplicative inverse satisfying Axiom (vii). Again, this is accomplished simply by inspection, building on our already established result that \(a=0\) and \(b=1\text{.}\) In detail, since \(a+a=a=0\) and \(b+b=a=0\text{,}\) we see that \(-a=a\) and \(-b=b\text{.}\) Turning at last to multiplicative inverses, note first that \(b\) is the only nonzero element of \(F\) (since \(a=0\)). Furthermore, since \(bb=b=1\text{,}\) we see that \(b^{-1}=b\text{.}\)
    🔗
    Since the operations on \(F\) satisfy the field axioms, we conclude that \(F\) is a field with respect to these operations. Having identified \(a=0\) and \(b=1\text{,}\) we can summarize the arithemetic rules of this particular field as follows:
    \begin{align*} 0+0 \amp =0 \amp 0+1\amp=1+0=1 \amp 1+1\amp =0 \\ 0\cdot 0 \amp = 0 \amp 0\cdot 1\amp =1\cdot 0=0 \amp 1\cdot 1\amp =1\\ -0 \amp =0 \amp -1\amp =1 \amp 1^{-1}\amp =1\text{.} \end{align*}
    🔗
    🔗
    🔗
    Take a moment to take in the exotic nature of the field in Example 1.2.14. Unlike \(\Q\) and \(\R\text{,}\) its underlying set is finite! Further peculiar attributes of this field is that every element is its own additive inverse. Crazy! Clearly, this example is important enough to warrant its own name.
    🔗

    Definition 1.2.15. Field of two elements.

    The set \(\F_2=\{0,1\}\text{,}\) together with the operations
    \begin{align*} 0+0 \amp = 0 \amp 0+1\amp=1+0=0 \amp 1+1\amp =0\\ 0\cdot 0\amp =0\amp 0\cdot 1\amp=1\cdot 0=0 \amp 1\cdot 1\amp = 1 \text{,} \end{align*}
    is called the field of two elements.
    🔗
    🔗

    Remark 1.2.16. Finite fields.

    It turns out that any finite field (i.e., a field \(F\) with finitely many elements) has prime cardinality. In other words if \(F\) is finite and we can define operations on \(F\) satisfying the field axioms, then \(\abs{F}=p\text{,}\) where \(p\) is a prime integer.
    🔗
    Furthermore, given any prime integer \(p\text{,}\) we can define addition and multiplication operations on the set \(\F_p=\{0,1,\dots, p-1\}\) that satisfy the field axioms. In other words, for every prime \(p\) there is a field of \(p\) elements. (These are things you learn in the Math 330/331 sequences.)
    🔗
    🔗
    We end with a proposition listing some basic further properties enjoyed by any field. Since we assume nothing about the underlying set \(F\) of the field, our proofs of these properties can invoke only the field axioms themselves.
    🔗

    Proposition 1.2.17. Basic properties of fields.

    Let \(F\) be a field.
    1. The additive and multiplicative identities \(0\) and \(1\) are unique.
      🔗
      🔗
    2. For all \(a\in F\text{,}\) we have \(0\cdot a=0\) and \((-1)a=-a\text{.}\)
      🔗
      🔗
    3. For all \(a,b,c\in F\) we have \(a=b\) if and only if \(a+c=b+c\text{.}\)
      🔗
      🔗
    4. For all \(a,b\in F\) and for all nonzero elements \(c\in F\text{,}\) we have \(a=b\) if and only if \(ac=bc\text{.}\)
      🔗
      🔗
    5. For all \(a,b\in F\text{,}\) if \(ab=0\text{,}\) then \(a=0\) or \(b=0\text{.}\)
      🔗
      🔗

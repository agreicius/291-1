Theorem 1.14.6. Determinant and invertibility.

Let \(A\in \ML_{n,n}(F)\text{.}\) The following conditions are equivalent.
  1. \(A\) is invertible.
    🔗
    🔗
  2. \(\det A\ne 0\text{.}\)
    🔗
    🔗
🔗
🔗

Proof.

Given \(A\in \ML_{n,n}(F)\) we can row reduce \(A\) to a matrix \(U\) in reduced row echelon form. Equivalently, we have
\begin{equation*} E_rE_{r-1}\cdots E_1A=U \end{equation*}
for some elementary matrices \(E_i\text{.}\) By Corollary 1.14.4, we have
\begin{align*} \right(\prod_{i=1}^r\det E_i\left)\det A \amp =\det U \text{.} \end{align*}
Since \(\det E_i\ne 0\) for all \(1\leq i\leq r\text{,}\) it follows that \(\det A\ne 0\) if and only if \(\det U\ne 0\text{.}\) Since \(U\) is in reduced row echelon form, it upper triangular, and hence \(\det U\ne 0\) if and only if \(U\) has a leading one in each column, if and only if \(U=I_n\text{.}\) Taken all together, we see that
\begin{align*} A \text{ invertible} \amp \iff U=I_n\\ \amp \iff \det U\ne 0\\ \amp \iff \det A\ne 0\text{.} \end{align*}

Definition 1.7.2. Linear equations.

Let \(F\) be a field. A linear expression over \(F\) in the \(n\) unknowns \(x_1,x_2,\dots x_n\) is an expression of the form
\begin{equation*} a_1x_1+a_2x_2+\cdots +a_nx_n+c\text{,} \end{equation*}
where \(a_1,a_2,\dots, a_n,c\in F\text{.}\)
🔗
A linear equation in the unknowns \(x_1,x_2,\dots, x_n\) is an equation that can be simplified, using only addition and subtraction, to an equation of the form
\begin{equation} a_1x_1+a_2x_2+\cdots a_nx_n=b,\tag{1.7.1} \end{equation}
which we call its standard form. An equation in the unknowns \(x_1,x_2,\dots, x_n\) is nonlinear if it cannot be simplified to the form (1.7.1) using only addition and subtraction.
🔗
A linear equation in standard form (1.7.1) is nontrivial if \(a_i\ne 0\) for some \(1\leq i\leq n\text{.}\) It is homogeneous if \(b=0\) and nonhomogeneous if \(b\ne 0\text{.}\)

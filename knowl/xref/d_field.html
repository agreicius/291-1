Definition 1.2.5. Field.

A field is a set \(F\) together with two operations
\begin{align*} +\colon F\times F \amp\rightarrow F \amp \times\colon F\times F\amp \rightarrow F \\ (a,b)\amp\mapsto a+b \amp (a,b)\amp \mapsto a\,b \end{align*}
called addition and multiplication respectively, satisfying the following axioms.
  1. Commutativity.
    For all \(a,b\in F\) we have
    \begin{align*} a+b \amp = b+a \amp ab=ba\text{.} \end{align*}
    🔗
    🔗
  2. Associativity.
    For all \(a,b,c \in F\) we have
    \begin{align*} a+(b+c)\amp =(a+b)+c \amp a(bc)=(ab)c\text{.} \end{align*}
    🔗
    🔗
  3. Distributivity.
    For all \(a,b,c \in F\) we have
    \begin{equation*} a(b+c)=ab+ac\text{.} \end{equation*}
    🔗
    🔗
  4. Additive identity.
    There is an element \(0\in F\) satisfying
    \begin{equation*} 0+a=a \end{equation*}
    for all \(a\in F\text{.}\) The element \(0\) is called the additive identity.
    🔗
    🔗
  5. Additive inverse.
    For all \(a\in F\) there is an element \(-a\in F\) satisfying
    \begin{equation*} a+ -a=0\text{.} \end{equation*}
    The element \(-a\) is called the additive inverse of \(a\text{.}\)
    🔗
    🔗
  6. Multiplicative identity.
    There is an element \(1\in F\) satisfying
    \begin{equation*} 1\times a=a \end{equation*}
    for all \(a\in F\text{.}\) The element \(1\) is called the multiplicative identity.
    🔗
    🔗
  7. Multiplicative inverse.
    For all nonzero elements \(a\in F\) (i.e., \(a\ne 0\)) there is an element \(a^{-1}\in F\) satisfying
    \begin{equation*} a\,a^{-1}=1\text{.} \end{equation*}
    The element \(a^{-1}\text{,}\) also denoted \(1/a\text{,}\) is called the multiplicative inverse of \(a\text{.}\)
    🔗

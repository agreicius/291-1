Proposition 1.2.17. Basic properties of fields.

Let \(F\) be a field.
  1. The additive and multiplicative identities \(0\) and \(1\) are unique.
    🔗
    🔗
  2. For all \(a\in F\text{,}\) we have \(0\cdot a=0\) and \((-1)a=-a\text{.}\)
    🔗
    🔗
  3. For all \(a,b,c\in F\) we have \(a=b\) if and only if \(a+c=b+c\text{.}\)
    🔗
    🔗
  4. For all \(a,b\in F\) and for all nonzero elements \(c\in F\text{,}\) we have \(a=b\) if and only if \(ac=bc\text{.}\)
    🔗
    🔗
  5. For all \(a,b\in F\text{,}\) if \(ab=0\text{,}\) then \(a=0\) or \(b=0\text{.}\)

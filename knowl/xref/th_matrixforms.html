Theorem 1.8.15. Row equivalent matrix forms.

  1. Row echelon forms exist.
    Any matrix \(A\) is row equivalent to a matrix in row echelon form. Indeed, applying Gaussian elimination to \(A\) produces a matrix in row echelon form that is row equivalent to \(A\text{.}\)
    🔗
    🔗
  2. Reduced row echelon forms exist.
    Any matrix \(A\) is row equivalent to a matrix in reduced row echelon form. Indeed, applying Gauss-Jordan elimination to \(A\) produces a matrix in reduced row echelon form that is row equivalent to \(A\text{.}\)
    🔗
    🔗
  3. Reduced row echelon forms are unique.
    Any matrix \(A\) is row equivalent to a unique matrix in reduced row echelon form.

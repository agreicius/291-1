Remark 1.6.2.

Let \(S\) be tuple of vectors in \(V\text{.}\)
  1. The zero vector is always an element of \(\Span S\text{.}\) We treat the cases where \(S\) is empty or nonempty separately.
    🔗
    If \(S=\emptyset\text{,}\) then \(\Span S=\{\boldzero\}\) by definition.
    🔗
    If \(S\ne \emptyset\text{,}\) then it contains some element \(v\in S\text{,}\) in which case by definition \(S\) contains all its scalar multiples \(cv\text{,}\) \(c\in F\text{.}\) By Proposition 1.4.15, we have \(\boldzero=0v\text{,}\) showing that \(\boldzero\in \Span S\text{.}\)
    🔗
    🔗
  2. The set \(S\) is contained in \(\Span S\text{.}\) Indeed, given any \(v\in S\text{,}\) we have \(v=1v\in \Span S\text{.}\)
    🔗
    🔗
  3. For any singleton \(S=\{v\}\text{,}\) we have \(\Span(v)=\{cv\colon c\in F\}\text{,}\) the set of all scalar multiples of \(v\text{.}\)
    🔗
    🔗

Procedure 1.8.13. Gauss-Jordan elimination.

Gauss-Jordan elimination is the algorithm described below. It takes as an input a matrix \(A\in \ML_{m\times n}(F)\) and returns a row equivalent matrix \(U\) in reduced row echelon form.
  1. Apply Gaussian elimination to transform \(A\) to a matrix \(B\) in row echelon form.
    🔗
    🔗
  2. Let \(1\leq j_1< j_2<\dots < j_r\leq n\) be the indices of the columns of \(B\) that contain leading ones. Beginning with the \(j_r\)-th column and working backwards, use row operations to replace all entries above the leading one in that column with zeros.

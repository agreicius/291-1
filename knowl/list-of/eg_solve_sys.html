Example 1.8.23. Solving linear systems.

Use Procedure 1.8.21 to describe the set of solutions \(S\) to the given linear system. Express your answer both in set notation form and, when appropriate, parametric equation form.
  1. \begin{equation*} 3x-y=6-x-y-z=x+z-1 \end{equation*}
    🔗
    🔗
  2. \begin{equation*} \begin{linsys}{4} x\amp +\amp y\amp +\amp z\amp +\amp w\amp =\amp 1\\ 2x\amp +\amp 2y\amp +\amp 2z\amp +\amp 2w\amp = \amp 3 \\ 2x\amp +\amp 2y\amp -\amp z\amp \amp \amp =\amp -2 \\ 3x\amp +\amp 3y\amp +\amp 2z\amp\amp \amp =\amp 0 \end{linsys} \end{equation*}
    🔗
    🔗
  3. \begin{equation*} \begin{linsys}{5} x_1\amp +\amp x_2\amp +\amp x_3\amp +\amp x_4+\amp x_5 \amp =\amp 1\\ \amp +\amp \amp +\amp x_3\amp -\amp x_4\amp+\amp 2x_5\amp =\amp 1\\ x_1\amp + \amp x_2 \amp +\amp 2x_3\amp \amp \amp+\amp 3x_5\amp =\amp 2 \end{linsys} \end{equation*}
    🔗
    🔗
🔗
Solution.
  1. First observe, using the fact that equality is transitive, that \((x,y,z)\) solves this chain of two equalities if and only if it solves the system
    \begin{equation*} \begin{linsys}{2} 3x\amp -\amp y\amp =\amp 6-x-y-z\\ 3x\amp -\amp y\amp =\amp x+z-1 \end{linsys}\text{,} \end{equation*}
    which in standard form is
    \begin{equation*} \begin{linsys}{3} 4x\amp \amp \amp +\amp z\amp =\amp 6\\ 2x\amp -\amp y\amp -\amp z\amp =\amp -1 \end{linsys}\text{.} \end{equation*}
    The augmented matrix of the system row reduces as
    \begin{equation*} \begin{amatrix}[rrr|l] 4\amp 0\amp 1\amp 6\\ 2\amp -1\amp -1\amp -1 \end{amatrix} \xrightarrow[]{\text{row ops}}\begin{amatrix}[rrr|l] \boxed{1}\amp 0\amp \frac{1}{4}\amp \frac{3}{2}\\ 0\amp \boxed{1}\amp \frac{3}{2}\amp 4 \end{amatrix}\text{,} \end{equation*}
    as you can check yourself (or with the help of Sage Example 1).
    🔗
    Since the leading ones of the reduced matrix appear only in the first two columns, the first two unknowns \(x\) and \(y\) are leading variables, and the last unknown \(z\) is free. Taking the corresponding system
    \begin{equation*} \begin{linsys}{3} x\amp \amp +\amp \frac{1}{4}z\amp =\amp \frac{3}{2}\\ \amp \amp y\amp +\amp \frac{3}{2}z\amp =\amp 4 \end{linsys} \end{equation*}
    and solving for the leading variables in terms of the free variables yields
    \begin{align*} x \amp = \frac{3}{2}-\frac{1}{4}z \\ y \amp = 4-\frac{3}{2}z\text{.} \end{align*}
    The parametric equations description of the general solution is then
    \begin{align*} z \amp =t \amp t\in \R \\ x \amp =\frac{3}{2}-\frac{1}{4}t\\ y \amp = 4-\frac{3}{2}t\text{.} \end{align*}
    Using set notation, the set of solutions \(S\) is
    \begin{equation*} S=\left\{\left(\tfrac{3}{2}-\tfrac{1}{4}t, 4-\tfrac{3}{2}t, t\right)\colon t\in \R\right\}\text{.} \end{equation*}
    🔗
    🔗
  2. In this case the augmented matrix of the system row reduces as
    \begin{equation*} \begin{amatrix}[rrrr|r] 1\amp 1\amp 1\amp 1\amp 1\\ 2\amp 2\amp 2\amp 2\amp 3\\ 2\amp 2\amp -1\amp 0\amp -2\\ 3\amp 3\amp 2\amp 0\amp 0 \end{amatrix} \xrightarrow[]{\text{row ops}}\begin{amatrix}[rrrr|r] \boxed{1}\amp 1\amp 1\amp 1\amp 1\\ 0\amp 0\amp \boxed{1}\amp \tfrac{2}{3}\amp \tfrac{4}{3}\\ 0\amp 0\amp 0\amp \boxed{1}\amp \tfrac{5}{7}\\ 0\amp 0\amp 0\amp 0\amp \boxed{1} \end{amatrix}\text{.} \end{equation*}
    Since the last column of the reduced matrix has a leading one, we conclude that the system is inconsistent, and hence has no solutions. Thus \(S=\emptyset\text{.}\)
    🔗
    🔗
  3. In this case the augmented matrix of the system row reduces as
    \begin{equation*} \begin{amatrix}[rrrrr|r] 1\amp 1\amp 1\amp 1\amp 1\amp 1\\ 0\amp 0\amp 1\amp -1\amp 2\amp 1\\ 1\amp 1\amp 2\amp 0\amp 3\amp 2 \end{amatrix} \xrightarrow[]{\text{row ops}}\begin{amatrix}[rrrrr|r] \boxed{1}\amp 1\amp 1\amp 1\amp 1\amp 1\\ 0\amp 0\amp \boxed{1}\amp -1\amp 2\amp 1\\ 0\amp 0\amp 0\amp 0\amp 0\amp 0 \end{amatrix}\text{.} \end{equation*}
    From the placement of the leading ones, we see that the first and third unknowns are leading, and the rest are free. Writing the leading variables in terms of the free ones, we have
    \begin{align*} x_3 \amp =1+x_4+2x_5\\ x_1 \amp = 1-x_2-x_3-x_4-x_5\\ \amp = -x_2-2x_4+3x_5\text{.} \end{align*}
    The parametric equations description of the general solution is then
    \begin{align*} x_2 \amp =s, x_4=t, x_5=u \amp s,t,u\in \R\\ x_3 \amp =1+t+2u\\ x_1 \amp =-s-2t+3u\text{.} \end{align*}
    Using set notation, the set of solutions \(S\) is
    \begin{equation*} S=\left\{(-s-2t+3u, s, 1+t+2u, t, u)\colon s,t,u\in \R\right\}. \end{equation*}

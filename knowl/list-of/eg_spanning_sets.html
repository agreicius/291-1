Example 1.6.5. Standard spanning sets.

For most of the vector spaces we’ve introduced there is a natural spanning set that comes to mind. We will refer to these loosely as standard spanning sets.
  • Zero space.
    Let \(V=\{\boldzero\}\text{.}\) By definition the empty set \(S=\emptyset\) is a spanning set of \(V\text{.}\) We call this the standard spanning set of the zero space.
    🔗
    🔗
  • \(n\)-tuples.
    Let \(V=F^n\text{.}\) We claim \(S=\{\bolde_1,\bolde_2,\dots, \bolde_n\}\) is a spanning set for \(V\text{,}\) which we call its standard spanning set. Indeed, given any \((a_1,a_2,\dots, a_n)\in F^n\) it is easy to see that
    \begin{equation*} (a_1,a_2,\dots, a_n)=\sum_{i=1}^na_i\bolde_i\text{.} \end{equation*}
    🔗
    🔗
  • Function space, finite domain.
    Recall that by definition \(F^n\) is simply notation for the function space \(\mathcal{F}(I,F)\text{,}\) where \(I=\{1,2,\dots, n\}\text{.}\) Thinking of the elements \(\bolde_i\) as functions \(f_i\colon I\rightarrow F\text{,}\) we see they are defined as \(f_i(j)=1\) if \(j=i\) and \(f_i(j)=0\text{,}\) otherwise. Such functions are called indicator functions (or characteristic functions) on the set \(I\text{.}\) As such we can generalize our result about \(F^n\) as follows.
    🔗
    Let \(V=\mathcal{F}(I,F)\text{,}\) where \(I\) is a finite nonempty set. For each \(i\in I\) define the function \(\chi_i\colon I\rightarrow F\) as follows:
    \begin{align*} \chi_i(j)=\begin{cases} 1\amp \text{if } j=i\\ 0\amp\text{if } j\ne i\end{cases} \amp \text{.} \end{align*}
    We claim that the set \(S=\{\chi_i\mid i\in I\}\) is a spanning set for \(\mathcal{F}(I,F)\text{.}\) Indeed given any function \(f\colon I\rightarrow F\text{,}\) consider the function
    \begin{equation*} g=\sum_{i\in I}f(i)\chi_i\in \Span S\text{.} \end{equation*}
    For all \(j\in I\text{,}\) we have
    \begin{align*} g(j) \amp =\sum_{i\in I}f(i)\chi_i(j)\\ \amp = f(j)\chi_j(j) \amp (\chi_i(j)=0 \text{ for } i\ne j)\\ \amp = f(j)\cdot 1 \amp (\chi_j(j)=1)\\ \amp = f(j)\text{.} \end{align*}
    We conclude that \(f=g\) and thus that \(f\in \Span S\text{.}\)

Example 1.6.10. Linear independence.

For each tuple \((v_i)_{i\in I}\) of the given vector space \(V\text{,}\) decide whether \((v_i)_{i\in I}\) is linearly independent.
  1. \(V=F^n\text{,}\) \((\bolde_i)_{i=1}^n\)
    🔗
    🔗
  2. \(V=\mathcal{F}(I, F)\text{,}\) \((\chi_i)_{i\in I}\text{,}\) where as usual, \(\chi_i\) is the \(i\)-th indicator function.
    🔗
    🔗
  3. \(V=\R^3\text{,}\) \((v_1,v_2,v_3)\text{,}\) where
    \begin{align*} v_1 \amp = (1,0,2) \amp v_2\amp =(-1,0,2) \amp v_3=(1,0,6) \text{.} \end{align*}
    🔗
    🔗
🔗
Solution.
  1. The tuple is linearly independent. We show that the only linear combination of the \(\bolde_i\) equal to \(\boldzero\) is the trivial one:
    \begin{align*} \sum_{i=1}^nc_i\bolde_i=\boldzero \amp \implies (c_1,0,\dots,0)+(0,c_2,\dots,0)+\cdots (0,\dots, c_n)=\boldzero\\ \amp \implies (c_1,c_2,\dots, c_n)=(0,0,\dots, 0)\\ \amp \implies c_i=0 \text{ for all } i\in I \amp \text{.} \end{align*}
    🔗
    🔗
  2. The tuple \((\chi_i)_{i\in I}\) is linearly independent. Before showing this, take a moment to orient yourself in this vector space: in particular, note that the elements of the vector space are functions, and that the zero vector is the zero function, denoted \(0_I\text{.}\) Note also that we make no assumptions on \(I\text{:}\) in particular, our proof should work whether or not \(I\) is infinite.
    🔗
    Take any tuple \((c_i)_{i\in I}\in F^I\) satisfying \(c_i=0\) for all but finitely many \(i\in I\text{.}\) We have
    \begin{align*} \sum_{i\in I}c_i\chi_i=0_I \amp \iff \sum_{i\in I}c_i\chi_i (j)=0 \text{ for all } j\in I \amp (\text{def. of func. equality}) \\ \amp \implies c_j\chi_j(j)=0 \text{ for all } j\in I \amp (\chi_i(j)=0 \text{ for all } i\ne j) \\ \amp \implies c_j=0 \text{ for all } j\in I \amp (\chi_j(j)=1 \text{ for all } j\in I) \text{.} \end{align*}
    We conclude that \((\chi_i)_{i\in I}\) is linearly independent.
    🔗
    Observe that the previous example is just the special case of this example where \(I=\{1,2\dots, n\}\text{,}\) since the tuple \(\bolde_i\) is really just the indicator function \(\chi_i\) in disguise!
    🔗
    🔗
  3. We observer, by inspection that
    \begin{equation*} 2\boldv_1+\boldv_2=\boldv_3\text{,} \end{equation*}
    and hence that
    \begin{equation*} 2\boldv_1+1\boldv_2+(-1)\boldv_3=\boldzero \end{equation*}
    is a nontrivial linear combination of the \(v_i\) equal to \(\boldzero\text{.}\) We conclude that the tuple \((v_1,v_2,v_3)\) is linearly dependent.
    🔗
    You might be somewhat uncomfortable with this “by inspection” approach. Fear not! We will soon develop a procedure for solving systems of linear equations that we can then apply to answering questions like this in a systematic manner.

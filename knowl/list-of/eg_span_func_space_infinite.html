Example 1.6.6. Function space, infinite domain.

Let \(F\) be a field, let \(V=\mathcal{F}(\N, F)\text{,}\) the set of functions from \(\N=\{0,1,\dots\}\) to \(F\text{,}\) and for all \(i\in \N\text{,}\) let \(\chi_i\colon \N\rightarrow F\) be the indicator function defined as \(\chi_i(n)=1\) if \(n=1\) and \(\chi_i(n)=0\) if \(n\ne i\text{.}\) Show that \(S=\{\chi_i\mid i\in \N\}\) does not span \(V\) by producing an explicit function \(f\colon \N\rightarrow F\) that cannot be written as a linear combination of the \(\chi_i\text{.}\)
🔗
Solution.
Consider the function \(f\colon \N\rightarrow F\) defined by \(f(n)=1\) for all \(n\in \N\text{.}\) We claim that \(f\notin \Span S\text{.}\) In fact, we will show that any \(g\in \Span S\) satisfies \(g(n)=0\) for all but finitely many \(n\in \N\text{.}\) It then follows that \(f\notin\Span S\) since \(f\) is nonzero for all \(n\in N\text{.}\)
🔗
To prove the claim, note that by definition, any \(g\in \Span S\text{,}\) is of the form
\begin{equation*} g=\sum_{j=1}^k c_{i_j}\chi_{i_j}\text{.} \end{equation*}
But then for all \(n\) in the infinite set
\begin{equation*} \N-\{i_1,i_2,\dots, i_k\}\text{,} \end{equation*}
we have
\begin{align*} g(n) \amp =\sum_{j=1}^kc_{i_j}\chi_{i_j}(n)\\ \amp =\sum_{j-1}^kc_{i_j}0 \amp (n\ne i_j\implies \chi_{i_j}(n)=0)\\ \amp = 0\text{,} \end{align*}
showing that \(g(n)=0\) for all but finitely many \(n\in \N\text{.}\)

Procedure 1.8.11. Gaussian elimination.

Gaussian elimination is the algorithm described below. It takes as an input a matrix \(A\in M_{m,n}(F)\) and returns as an output a row equivalent matrix \(U\) in row echelon form.
  1. If \(A\) is the zero matrix, then return \(A\text{.}\) Otherwise, find the first nonzero column of \(A\text{:}\) i.e., find the smallest integer \(j\in \{1,2,\dots, n\}\) for which the \(j\)-th column is nonzero. Let \(i\) be the smallest integer in \(\{1,2,\dots, m\}\) such that \(a_{i,j}\ne 0\text{.}\) Use a row swap to move \(a_{i,j}\) to the top of the column.
    🔗
    🔗
  2. Scale the new top row to produce a leading one in the \((1,j)-th\) entry of the matrix.
    🔗
    🔗
  3. For each \(1< i\leq m\text{,}\) perform a row operation of the form \(r_i+c\,r\) to replace \(a_{i,j}\) with \(0\text{:}\) i.e., make all the entries below the leading one produced in Step 2 equal to zero.
    🔗
    🔗
  4. If \(A\) consists of one row, stop. Otherwise, apply steps 1-4 to the submatrix of \(A\) obtained by deleting its first row. In more detail, let \(A'=[a_{i+1,j}]\in \ML_{m-1,n}(F)\text{,}\) apply steps 1-4 to \(A'\) to obtain a matrix \(U'=[u'_{i,j}]\in \ML_{m-1,n}(F)\text{,}\) and replace \(a_{i,j}\) with \(u'_{i-1,j}\) for all \(2\leq i\leq m\text{.}\)

Definition 1.6.1. Span.

Let \(S\) be a subset of the \(F\)-vector space \(V\text{.}\) The span of \(S\text{,}\) denoted \(\Span S\text{,}\) is defined as follows.
  • If \(S=\emptyset\text{,}\) then we define
    \begin{equation*} \Span S=\Span\emptyset=\{\boldzero\}\text{.} \end{equation*}
    🔗
    🔗
  • If \(S\ne \emptyset\text{,}\) then we define \(\Span S\) as the set of all linear combinations of the vectors in \(S\text{:}\) i.e.,
    \begin{equation*} \Span S=\{v\in V\colon v=\sum_{k=1}^nc_{k}v_{k} \text{ for some } n\in \Z_+, v_k\in S, c_{k}\in F\} \text{.} \end{equation*}

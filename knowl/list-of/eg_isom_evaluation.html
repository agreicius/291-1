Example 1.21.9 Evaluation.

Let \(c_1,c_2,\dots, c_{k}\) be \(n+1\) distinct scalars of the field \(F\) and define \(T\colon F_{\deg\leq n}[x]\rightarrow F^{k}\) as \(T(f)=(f(c_i))_{i=1}^k\text{.}\)
  1. Prove: \(T\) is a linear transformation.
    🔗
    🔗
  2. Prove: \(T\) is in injective if and only if \(k\geq n+1\text{.}\)
    🔗
    🔗
  3. Prove: \(T\) is surjective if and only if \(k\leq n+1\text{.}\)
    🔗
    🔗
  4. Prove: \(T\) is an isomorphism if and only if \(k=n+1\text{.}\)
    🔗
    🔗
🔗
Solution.
We showed in Example 1.20.8 that this linear transformation is bijective, and hence an isomorphism.

Example 0.2.3. Arithmetic operations as functions.

Our familiar arithmetic operations can be expressed as functions whose inputs are pairs of numbers. Using the notational conventions introduced in Definition 0.2.1 (with function names supressed), addition is the function
\begin{align*} \R\times \R \amp\rightarrow \R \\ (x,y) \amp\mapsto x+y \text{,} \end{align*}
and multiplication is the function
\begin{align*} \mathbb{R}\times \mathbb{R} \amp \rightarrow \mathbb{R}\\ (x,y)\amp\mapsto xy \text{.} \end{align*}

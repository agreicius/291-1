Example 1.8.33. Span and linear independence.

For each vector space \(V\) and tuple of vectors \((v_{i})_{i\in I}\) determine (i) whether the tuple is linearly independent, and (ii) determine \(W=\Span (v_{i})_{i\in I}\text{.}\)
  1. \(V=\C^{3}\text{,}\) \((\boldv_{1},\boldv_{2},\boldv_{3})\text{,}\) where
    \begin{align*} \boldv_{1}\amp =(1+i,1-i,-2) \amp \boldv_{2}\amp =(-2i,1,-1+2i)\amp \boldv_{3}\amp =(3,-2,-1) \end{align*}
    🔗
    🔗
  2. \(V=\ML_{2,2}(\R)\text{,}\) \((A_{1},A_{2},A_{3},A_{4})\text{,}\) where
    \begin{align*} A_{1}\amp =\begin{amatrix}[rr]1\amp 1\\ 1\amp 1\end{amatrix}\amp A_{2}\amp =\begin{amatrix}[rr]1\amp -1\\ 0\amp 0\end{amatrix}\\ A_{3}\amp =\begin{amatrix}[rr]0\amp 0\\ 1\amp -1\end{amatrix}\amp A_{4}\amp =\begin{amatrix}[rr]1\amp 1\\ -1\amp -1\end{amatrix} \end{align*}
    🔗
    🔗
  3. \(V=\ML_{2,2}(\R)\text{,}\) \((A_{1},A_{2},A_{3},A_{4})\text{,}\) where
    \begin{align*} A_{1}\amp =\begin{amatrix}[rr]1\amp 1\\ 1\amp 1\end{amatrix}\amp A_{2}\amp =\begin{amatrix}[rr]1\amp -1\\ -1\amp 0\end{amatrix}\\ A_{3}\amp =\begin{amatrix}[rr]0\amp 0\\ 0\amp -1\end{amatrix}\amp A_{4}\amp =\begin{amatrix}[rr]1\amp 1\\ 1\amp 3\end{amatrix} \end{align*}
    🔗
    🔗
🔗
Solution 1.
First we decide whether \((\boldv_1,\boldv_2,\boldv_3)\) is linearly independent. To this end, we ask whether there is a nonzero triple \((c_1,c_2,c_3)\in \C^3\) such that \(\sum_{i=1}^3c_i\boldv_i=\boldzero\text{.}\) Expanding the linear combination on the left and setting each coordinate equal to 0 yields the linear system
\begin{equation*} \begin{linsys}{3} (1+i)c_1\amp -\amp 2i\, c_2\amp +\amp 3c_3\amp = \amp 0\\ (1-i)c_1\amp +\amp c_2\amp -\amp 2c_3\amp = \amp 0\\ -2c_1\amp +\amp (-1+2i)c_2\amp -\amp c_3\amp = \amp 0 \end{linsys}\text{.} \end{equation*}
We apply Procedure 1.8.21 to this system:
\begin{align*} \begin{amatrix}[rrr|r] 1+i\amp -2i\amp 3\amp 0\\ 1-i\amp 1\amp -2\amp 0\\ -2\amp -1+2i\amp -1\amp 0 \end{amatrix}\amp\xrightarrow{(1+i)^{-1}r_1}\\ \begin{amatrix}[rrr|r] 1\amp -1-i\amp \frac{3}{2}(1-i)\amp 0\\ 1-i\amp 1\amp -2\amp 0\\ -2\amp -1+2i\amp -1\amp 0 \end{amatrix} \amp\xrightarrow{r_2-(1-i)r_1} \\ \begin{amatrix}[rrr|r] 1\amp -1-i\amp \frac{3}{2}(1-i)\amp 0\\ 0\amp 3\amp -2-3i\amp 0\\ -2\amp -1+2i\amp -1\amp 0 \end{amatrix} \amp\xrightarrow{r_3+2r_1} \\ \begin{amatrix}[rrr|r] 1\amp -1-i\amp \frac{3}{2}(1-i)\amp 0\\ 0\amp 3\amp -2-3i\amp 0\\ 0\amp -3\amp 2-3i\amp 0 \end{amatrix}\amp\xrightarrow{\frac{1}{3}r_2} \\ \begin{amatrix}[rrr|r] 1\amp -1-i\amp \frac{3}{2}(1-i)\amp 0\\ 0\amp 1\amp -\frac{1}{3}(2+3i)\amp 0\\ 0\amp -3\amp 2\amp 0 \end{amatrix}\amp\xrightarrow{r_3+3r_2} \\ \begin{amatrix}[rrr|r] \boxed{1}\amp -1-i\amp \frac{3}{2}(1-i)\amp 0\\ 0\amp \boxed{1}\amp -\frac{3}{2}\amp 0\\ 0\amp 0\amp 0\amp 0 \end{amatrix}\amp\text{.} \end{align*}
We see that the system is consistent and that the unknown \(c_3\) is free. It follows that there are infinitely many solutions \((c_1,c_2,c_3)\) to the system, and thus in particular, a nonzero one. Thus there is a nonzero triple \((c_1,c_2,c_3)\) satisfying \(\sum_{i=1}^3c_i\boldv_i=\boldzero\text{,}\) and we conclude that the tuple \((\boldv_1,\boldv_2,\boldv_3)\) is linearly dependent.
🔗
To determine \(W=\Span(\boldv_i)_{i=1}^3\text{,}\) we ask which triples \(\boldv=(z_1,z_2,z_3)\in \C^3\) can be expressed as \(\boldv=\sum_{i=1}^3c_i\boldv_i\) for some some \(c_i\in \C\text{.}\) This is equivalent to asking for which triples \((z_1,z_2,z_3)\) is the linear system
\begin{equation*} \begin{linsys}{3} (1+i)c_1\amp -\amp 2i\, c_2\amp +\amp 3c_3\amp = \amp z_1\\ (1-i)c_1\amp +\amp c_2\amp -\amp 2c_3\amp = \amp z_2\\ -2c_1\amp +\amp (-1+2i)c_2\amp -\amp c_3\amp = \amp z_3 \end{linsys} \end{equation*}
consistent. Once again, we apply Procedure 1.8.21. Observe how we can reuse much of the work we did above. We will take some shortcuts in our Gaussian elimination for brevity:
\begin{align*} \begin{amatrix}[rrr|r] 1+i\amp -2i\amp 3\amp z_1\\ 1-i\amp 1\amp -2\amp z_2\\ -2\amp -1+2i\amp -1\amp z_3 \end{amatrix}\amp\xrightarrow{(1+i)^{-1}r_1}\\ \begin{amatrix}[rrr|r] 1\amp -1-i\amp \frac{3}{2}(1-i)\amp \frac{1}{1+i}\, z_1\\ 1-i\amp 1\amp -2\amp z_2\\ -2\amp -1+2i\amp -1\amp z_3 \end{amatrix} \amp\xrightarrow{r_2-(1-i)r_1} \\ \begin{amatrix}[rrr|r] 1\amp -1-i\amp \frac{3}{2}(1-i)\amp \frac{1}{1+i}\, z_1\\ 0\amp 3\amp -2-3i\amp z_2-\frac{1-i}{1+i}\, z_1\\ -2\amp -1+2i\amp -1\amp z_3 \end{amatrix} \amp\xrightarrow{r_3+2r_1} \\ \begin{amatrix}[rrr|r] 1\amp -1-i\amp \frac{3}{2}(1-i)\amp \frac{1}{1+i}\, z_1 \\ 0\amp 3\amp -2-3i\amp z_2-\frac{1-i}{1+i}\, z_1\\ 0\amp -3\amp 2-3i\amp z_3+\frac{2}{1+i}\, z_1 \end{amatrix}\amp\xrightarrow{r_3+r_2} \\ \begin{amatrix}[rrr|r] 1\amp -1-i\amp \frac{3}{2}(1-i)\amp \frac{1}{1+i}\, z_1\\ 0\amp 3\amp -(2+3i)\amp z_2-\frac{1-i}{1+i}\, z_1\\ 0\amp 0\amp 0\amp z_3+\frac{2}{1+i}\, z_1+\left(z_2-\frac{1-i}{1+i}\, z_1\right) \end{amatrix}\amp \text{.} \end{align*}
At this point we see that the system is consistent if and only if
\begin{equation*} 0=z_3+\frac{2}{1+i}\, z_1+\left(z_2-\frac{1-i}{1+i}\, z_1\right)=z_1+z_2+z_3\text{.} \end{equation*}
We conclude that
\begin{equation*} W=\Span (v_i)_{i=1}^3=\{(z_1,z_2,z_3)\in \C\mid z_1+z_2+z_3=0\}\text{.} \end{equation*}
🔗

Solution 2.
As the last example illustrates, when answering the two questions posed separately, we repeat a lot of the same Gaussian elimination work. Let’s change things up slightly here and consider first the span question. We ask which matrices \(A=\begin{bmatrix}a\amp b\\ c\amp d\end{bmatrix}\) can be expressed as \(A=\sum_{i=1}^4c_iA_i\) for some \(c_i\in \R\text{.}\) Expanding out the linear combination of the \(A_i\text{,}\) this equality becomes
\begin{align} \begin{amatrix}[rr] c_1+c_2+c_4 \amp c_1-c_2+c_4 \\ c_1+c_3-c_4 \amp c_1-c_3-c_4 \end{amatrix} \amp = \begin{amatrix}[rr] a \amp b \\ c \amp d \end{amatrix} \text{.}\tag{1.8.8} \end{align}
Equating the entries of both matrice, we see that the span question is equivalent to asking for which \(4\)-tuples \((a,b,c,d)\) the linear system
\begin{equation*} \begin{linsys}{4} c_1+c_2+c_4\amp =\amp a\\ c_1-c_2+c_4\amp =\amp b\\ c_1+c_3-c_4\amp =\amp c\\ c_1-c_3-c_4\amp =\amp d \end{linsys} \end{equation*}
is consistent. We apply Procedure 1.8.21 to this system:
\begin{align*} \begin{amatrix}[rrrr|r] 1\amp 1\amp 0\amp 1\amp a\\ 1\amp -1\amp 0\amp 1\amp b\\ 1\amp 0\amp 1\amp -1\amp c\\ 1\amp 0\amp -1\amp -1\amp d \end{amatrix}\amp \xrightarrow{r_2-r_1} \begin{amatrix}[rrrr|r] 1\amp 1\amp 0\amp 1\amp a\\ 0\amp -2\amp 0\amp 0\amp b-a\\ 1\amp 0\amp 1\amp -1\amp c\\ 1\amp 0\amp -1\amp -1\amp d \end{amatrix}\\ \amp \xrightarrow{r_3-r_1} \begin{amatrix}[rrrr|r] 1\amp 1\amp 0\amp 1\amp a\\ 0\amp -2\amp 0\amp 0\amp b-a\\ 0\amp -1\amp 1\amp -2\amp c-a\\ 1\amp 0\amp -1\amp -1\amp d \end{amatrix} \\ \amp \xrightarrow{r_4-r_1}\begin{amatrix}[rrrr|r] 1\amp 1\amp 0\amp 1\amp a\\ 0\amp -2\amp 0\amp 0\amp b-a\\ 0\amp -1\amp 1\amp -2\amp c-a\\ 0\amp -1\amp -1\amp -2\amp d-a \end{amatrix}\\ \amp \xrightarrow{-\frac{1}{2}r_2}\begin{amatrix}[rrrr|r] 1\amp 1\amp 0\amp 1\amp a\\ 0\amp 1\amp 0\amp 0\amp \frac{1}{2}(a-b)\\ 0\amp -1\amp 1\amp -2\amp c-a\\ 0\amp -1\amp -1\amp -2\amp d-a \end{amatrix} \\ \amp \xrightarrow{r_3+r_2}\begin{amatrix}[rrrr|r] 1\amp 1\amp 0\amp 1\amp a\\ 0\amp 1\amp 0\amp 0\amp \frac{a}{2}-\frac{b}{2}\\ 0\amp 0\amp 1\amp -2\amp -\frac{a}{2}-\frac{b}{2}+c\\ 0\amp -1\amp -1\amp -2\amp d-a \end{amatrix} \\ \amp \xrightarrow{r_4+r_2}\begin{amatrix}[rrrr|r] 1\amp 1\amp 0\amp 1\amp a\\ 0\amp 1\amp 0\amp 0\amp \frac{a}{2}-\frac{b}{2}\\ 0\amp 0\amp 1\amp -2\amp \frac{a}{2}-\frac{b}{2}+c\\ 0\amp 0\amp -1\amp -2\amp -\frac{a}{2}-\frac{b}{2}+d \end{amatrix}\\ \amp \xrightarrow{r_4+r_3} \begin{amatrix}[rrrr|r] 1\amp 1\amp 0\amp 1\amp a\\ 0\amp 1\amp 0\amp 0\amp \frac{a}{2}-\frac{b}{2}\\ 0\amp 0\amp 1\amp -2\amp \frac{a}{2}-\frac{b}{2}+c\\ 0\amp 0\amp 0\amp -4\amp -b+c+d \end{amatrix}\\ \amp\xrightarrow{-\frac{1}{4}r_4} \begin{amatrix}[rrrr|r] \boxed{1}\amp 1\amp 0\amp 1\amp a\\ 0\amp \boxed{1}\amp 0\amp 0\amp \frac{a}{2}-\frac{b}{2}\\ 0\amp 0\amp \boxed{1}\amp -2\amp \frac{a}{2}-\frac{b}{2}+c\\ 0\amp 0\amp 0\amp \boxed{1}\amp \frac{1}{4}(b-c-d) \end{amatrix} \text{.} \end{align*}
Since there are leading ones in all four of the columns corresponding to unknowns, we see that that system is always consistent, and furthermore, that for any \((a,b,c,d)\) there is a unique solution \((c_1,c_2,c_3,c_4)\text{.}\) We conclude that
\begin{align*} W=\Span (A_i)_{i=1}^4\amp =\ML_{2,2}(\R)\text{.} \end{align*}
In other words, \(\{A_1,A_2,A_3,A_4\}\) is a spanning set for \(\ML_{2,2}(\R)\text{.}\) Furthermore, our reasoning shows that for any matrix \(A\) there is a unique tuple \((c_1,c_2,c_3,c_4)\) satisfying \(\sum_{i=1}^4c_iA_i=A\text{.}\) In particular, taking \(A=\boldzero_{2\time 2}\text{,}\) we see that there is a unique tuple \((c_1,c_2,c_3,c_4)\) satisfying \(\sum_{i=1}^4c_iA_i=\boldzero\text{.}\) Since \((c_1,c_2,c_3,c_4)=(0,0,0,0)\) is such a tuple, we conclude that \(\sum_{i=1}^4c_iA_i=\boldzero\) implies \((c_1,c_2,c_3,c_4)=(0,0,0,0)\text{,}\) and thus \((A_1,A_2,A_3,A_4)\) is linearly independent.

Solution 3.
The work here is very similar to the previous part. In this case, tuples \((c_1,c_2,c_3,c_4)\) satisfying
\begin{equation*} c_1A_1+c_2A_2+c_3A_3+c_4A_4=\begin{bmatrix} a\amp b\\ c\amp d \end{bmatrix} \end{equation*}
correspond to solutions of the linear system with augmented matrix
\begin{equation*} \begin{amatrix}[rrrr|r] 1\amp 1\amp 0\amp 1\amp a\\ 1\amp -1\amp 0\amp 1\amp b\\ 1\amp -1\amp 0\amp 1\amp c\\ 1\amp 0\amp -1\amp 3\amp d \end{amatrix}\text{.} \end{equation*}
This matrix row reduces to the matrix
\begin{equation*} \begin{amatrix}[rrrr|r] \boxed{1}\amp 1\amp 0\amp 1\amp a\\ 0\amp \boxed{1}\amp 0\amp 0\amp \frac{1}{2}(a-b)\\ 0\amp 0\amp \boxed{1}\amp -2\amp \frac{1}{2}(a+b)-d\\ 0\amp 0\amp 0\amp 0\amp c-b \end{amatrix}\text{.} \end{equation*}
We conclude in this case that
\begin{align*} W=\Span (A_i)_{i=1}^4 \amp = \left\{\begin{bmatrix}a\amp b\\ c\amp d\end{bmatrix}\in \ML_{2,2}(\R)\mid b=c\right\}\\ \amp = \left\{\begin{bmatrix}a\amp b\\ b\amp d\mid a,b,d\in \R\right\}\text{,} \end{align*}
the set of all symmetric \(2\times 2\) matrices. The special case where we consider linear combinations of the form
\begin{equation*} c_1A_1+c_2A_2+c_3A_3+c_4A_4=\boldzero \end{equation*}
corresponds to the system where we set \(a=b=c=d=0\text{.}\) In this case, the system is consistent (as always, since it is homogenous), and the presence of a free variable implies that there are infinitely many tuples \((c_1,c_2,c_3,c_4)\) solving the system. This in turn implies that \((A_i)_{i=1}^4\) is linearly dependent, since there are then nontrivial linear combinations of the \(A_i\) equal to the zero matrix.

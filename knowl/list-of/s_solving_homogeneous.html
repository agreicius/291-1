Corollary 1.8.30. Solutions to homogeneous equations.

Let \(F\) be an infinite field (e.g., \(\Q\text{,}\) \(|R\text{,}\) \(\C\)), and let \(L\) be a homogeneous linear system over \(F\text{.}\)
  1. If all the variables are leading variables, then the system has a unique solution (i.e., \(1\) solution).
    🔗
    🔗
  2. If there is a free variable, then the system has infinitely many solutions.

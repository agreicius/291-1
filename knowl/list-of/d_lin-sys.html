Definition 1.7.5. Systems of linear equations.

Let \(F\) bea field. A system of linear equations (or linear system) over \(F\) is a set of linear equations.
\begin{equation} \eqsys\tag{1.7.2} \end{equation}
The scalars \(a_{i,j}\) are called the coefficients of the system. The linear system (1.7.2) is homogeneous if each of its equations is homogeneous: i.e., if \(b_i=0\) for all \(1\leq i\leq m\text{.}\)
🔗
A solution to the system (1.7.2) is an \(n\)-tuple \((s_1,s_2,\dots,s_n)\in F^n\) that is a solution to each of the system’s \(m\) equations. We say \((s_1,s_2,\dots, s_n)\) solves the system in this case.
🔗
A linear system is consistent if a solution to the system exists, and inconsistent otherwise.

Example 1.20.16. Formal polynomials and polynomial functions.

Let \(n\) be a positive integer and let \(I\) be a nonempty subset of the field \(F\text{.}\) The function \(T\colon F[x]_{\deg\leq n}\rightarrow P_n(I)\) that sends a formal polynomial \(f\in F[x]_{\deg\leq n}\) to the polynomial function on \(I\) it represents is easily seen to be a linear transformation.
  1. Show that \(\im T=P_n(I)\text{,}\) or equivalently, that \(T\) is surjective.
    🔗
    🔗
  2. Describe \(\NS T\) in terms of the elements of \(I\text{.}\)
    🔗
    🔗
  3. Prove:
    \begin{equation*} \dim\NS T=\begin{cases} 0\amp \text{if } \val{I}\geq n+1\\ n+1-\val{I}\amp \text{if } \val{I}\leq n \end{cases} \end{equation*}
    🔗
    🔗
  4. Prove:
    \begin{equation*} \dim P_n(I)=\begin{cases} n+1\amp \text{if } \val{I}\geq n+1\\ \val{I}\amp \text{if } \val{I}\leq n \end{cases} \end{equation*}
    🔗
    🔗
🔗

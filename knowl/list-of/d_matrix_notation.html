Definition 1.9.2. Matrix notation.

  • Matrix-building notation.
    The notation \([a_{i,j}]_{m\times n}\) denotes the \(m\times n\) matrix whose \(i,j\)-th entry is \(a_{i,j}\) for all \(1\leq i\leq m, 1\leq j\leq n\text{.}\) When there is no danger of confusion, this notation is often shortened to \([a_{i,j}]\text{.}\)
    🔗
    🔗
  • Matrix entry notation.
    Given a matrix \(A\text{,}\) the notation \([A]_{i,j}\) denotes the \(i,j\)-th entry of \(A\text{.}\)
    🔗
    🔗
Thus if \(A=[a_{i,j}]_{m\times n}\text{,}\) then \([A]_{i,j}=a_{i,j}\) for all \(1\leq i\leq m\) and \(1\leq j\leq n\text{.}\)

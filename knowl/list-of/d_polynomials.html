Definition 1.16.6. Polynomial functions.

Let \(F\) be a field, and let \(I\) be a nonempty subset of \(F\text{.}\) Given a nonnegative integer \(n\text{,}\) we define \(P_n(I)\) to be the set of all polynomial functions on \(I\) of degree at most \(n\text{:}\) i.e.,
\begin{equation*} P_n(I)=\{f\in \mathcal{F}(I,F)\mid f(x)=g(x) \text{ for all } x\in I \text{ for some } g\in F[x] \text{ with } \deg g\leq n\}\text{.} \end{equation*}
Lastly we define \(P(I)\) to be the set of all polynomial functions on \(I\text{.}\) Since any polynomial on \(I\) is of the form \(f(x)=\anpoly\) for some \(n\in \Z_{\geq 0}\text{,}\) we have
\begin{equation*} P(I)=\bigcup_{n=0}^\infty P_n(I)\text{.} \end{equation*}

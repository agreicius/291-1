Definition 1.5.1. \(F\)-valued \(n\)-tuples.

Let \(F\) be a field, and let \(n\) be a positive integer. An \(F\)-valued \(n\)-tuple is a function \(f\colon \{1,2,\dots, n\}\rightarrow F\text{.}\) In this setting, we will use an alternative tuple notation, writing
\begin{equation*} f=(a_i)_{i=1}^n=(a_1,a_2,\dots, a_n)\text{,} \end{equation*}
where \(a_i=f(i)\text{,}\) the value of \(f\) at \(i\text{,}\) for all \(i\in \{1,2,\dots, n\}\text{.}\) We will also favor letters like \(v,w,u\) to denote \(n\)-tuples, as opposed to \(f,g,h\text{.}\)
🔗
Given an \(n\)-tuple \(v=(a_i)_{i=1}^n\text{,}\) we call \(n\) the length of \(v\text{,}\) and for each index \(i\in \{1,2,\dots, n\}\text{,}\) we call \(a_i\) the \(i\)-th component (or coordinate, or entry, or term) of \(v\text{.}\)
🔗
The set of all \(F\)-valued \(n\)-tuples is denoted \(F^n\text{:}\) i.e.,
\begin{equation*} F^n=\{(a_i)_{i=1}^n\mid a_i\in \F \text{ for all } i=1,2,\dots, n\}\text{.} \end{equation*}

Example 1.17.8. One-step basis technique.

Use Procedure 1.17.7 to decide whether \(B\) is a basis of \(V\text{.}\)
  1. \(V=\C[x]_{\deg \leq 2}\text{,}\) \(B=(p_1(x)=x^2+x+1, p_2(x)=x+1, p_3(x)=-x+1)\)
    🔗
    🔗
  2. \(V=\ML_{2,2}(F)\text{,}\) \(B=\left(A_1=\begin{amatrix}[rr] 1\amp 1\\ 1\amp 1 \end{amatrix}, A_2=\begin{amatrix}[rr] 0\amp 1\\ 1\amp 1 \end{amatrix}, A_3=\begin{amatrix}[rr] 0\amp 1\\ -1\amp 0 \end{amatrix} \right)\)
    🔗
    🔗
🔗
Solution.
  1. We must show that given any polynomial \(f(x)=ax^2+bx+c\in \C[x]_{\deg\leq 2}\text{,}\) there is a unique tuple \((c_1,c_2,c_3)\in F^3\) such that
    \begin{equation*} f=c_1p_1+c_2p_2+c_3p_3\text{.} \end{equation*}
    Writing out the right side linear combination in standard polynomial form and equating coefficients, we see that this is equivalent to the linear system
    \begin{equation*} \begin{linsys}{3} c_1\amp\amp \amp\amp \amp=\amp a \\ c_1\amp+\amp c_2\amp-\amp c_3\amp=\amp b \\ c_1\amp+\amp c_2\amp+\amp c_3\amp=\amp c \end{linsys}\text{.} \end{equation*}
    It is then easy to see (using Gaussian elimination or proceeding in an ad hoc manner) that for any \(a,b,c\text{,}\) this system has the unique solution
    \begin{align*} c_1 \amp = a \amp c_2\amp=\frac{1}{2}(-2a+b+c) \amp c_3\amp=\frac{1}{2}(c-b) \text{.} \end{align*}
    We conclude that \(B\) is a basis of \(V\) by Theorem 1.17.5.
    🔗
    🔗
  2. We as whether for any matrix \(A=\abcdmatrix{a}{b}{c}{d}\) there is a unique tuple \((c_1,c_2,c_3,c_4)\) such that
    \begin{equation*} A=c_1A_1+c_2A_2+c_3A_3\text{.} \end{equation*}
    As above, combining the right side into a single matrix and equating entries, we see that this is equivalent to the linear system
    \begin{equation*} \begin{linsys}{3} c_1\amp+\amp \amp+\amp c_3\amp=\amp a \\ c_1\amp+\amp c_2\amp+\amp c_3\amp=\amp b \\ c_1\amp+\amp c_2\amp-\amp c_3\amp=\amp c \\ c_1\amp+\amp c_2\amp\amp \amp=\amp d \end{linsys} \end{equation*}
    having a unique solution for any \(a,b,c,d\in \F\text{.}\) Row reducing the corresponding augmented matrix yields the augmented matrix
    \begin{equation*} U=\begin{amatrix}[rrr|r] \boxed{1}\amp 0\amp 1\amp a\\ 0\amp \boxed{1}\amp 0\amp b-a\\ 0\amp 0\amp \boxed{1}\amp \frac{1}{2}(b-c)\\ 0\amp 0\amp 0\amp \frac{1}{2}(b+c-2d) \end{amatrix}\text{.} \end{equation*}
    We conclude that the corresponding system is consistent if and only if \(b+c-2d=0\text{,}\) and thus for any matrix \(A\) with \(b+c-2d\neq 0\text{,}\) there is no solution to the system, and hence no linear combination of the \(A_i\) equal to \(A\text{.}\) We conclude that \(B\) does not span \(\ML_{2,2}(F)\) and hence is not a basis.
    🔗
    That said, the same computation shows that \(A=(B_1,B_2,B_3)\) is linearly independent, and hence is a basis for \(W=\Span(A_1,A_2,A_3)\text{,}\) which is the subspace of all matrices \(A=\abcdmatrix{a}{b}{c}{d}\) satisfying \(b+c-2d=0\text{.}\)

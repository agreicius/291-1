Example 1.21.8 Formal polynomials and polynomial functions.

Let \(I\) be a subset of the field \(F\text{.}\) The function \(T\colon F[x]\rightarrow P(I)\) that defines \(T(f)\) to be the function on \(I\) represented by \(f\) is a linear transformation.
  1. Prove: \(T\) is surjective.
    🔗
    🔗
  2. Prove: \(T\) is injective if and only if \(I\) is infinite.
    🔗
    🔗
  3. The restriction \(S=T\vert_{F[x]_{\deg \leq n}}\) of \(T\) to the subspace \(F[x]_{\deg\leq n}\) defines a linear transformation \(S\colon F[x]_{\deg\leq n}\rightarrow P_n(I)\text{.}\)
    🔗
    Prove: \(S\) is an isomorphism if and only if \(\abs{I}\geq n+1\text{.}\)
    🔗
    🔗
🔗
Solution.

Definition 1.11.10. Matrix powers.

Let \(A\) be an \(n\times n\) matrix, and let \(r\in\Z\) be an integer. We define the power matrix \(A^r\) as follows:
\begin{equation*} A^r=\begin{cases} I\amp \text{if } r=0;\\[2ex] \underset{r \text{ times}}{\underbrace{AA\cdots A}}\amp \text{if } r>0; \\[2ex] (A^{-1})^s \amp \text{if } r=-s < 0 \text{ and } A \text{ is invertible}. \text{.}\end{cases} \end{equation*}
